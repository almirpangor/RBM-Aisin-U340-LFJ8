# Диагностика Chery

Карточки [DTC-01…04](../docs/project-map.md#dtc-01). Полный разбор — [diagnostics-integration.md](../docs/diagnostics-integration.md).

| Файл | Ответственность |
| --- | --- |
| [chery_dtc.c](chery_dtc.c) | Текущие признаки, пять слотов истории, чтение/очистка по таблице S03 |
| [chery_dtc_can.c](chery_dtc_can.c) | Формат одного и нескольких CAN-кадров |
| [chery_dtc_link.c](chery_dtc_link.c) | Ограниченный сеанс C0, токен TX, Flow Control и тайм-ауты |
| [chery_model_monitor.c](chery_model_monitor.c) | Квалификация потери двух полей модели двигателя |
| [lfj8_h03_dtc_can.c](../targets/lfj8/lfj8_h03_dtc_can.c) | Адаптер CAN0, TRFIN, поколение и свежесть |
| [lfj8_h03_engine_feed.c](../targets/lfj8/lfj8_h03_engine_feed.c) | RPM/ОЖ и общие U111F/U1100, очистка/восстановление |

Файлы test_* проверяют соответствующие слои. Native RX BasicCAN, постоянное хранение и все соответствия Toyota→Chery ведутся отдельными задачами. Проверенная история в RAM не означает сохранение после выключения питания. Кандидаты сопоставления кодов в документе не являются уже установленной таблицей мониторов.

Быстрая проверка — PC из карты проекта, процессорная — M32R. Аппаратная приёмка требует сканера в режиме Chery с контролируемыми отказами.
