## Independent native commissioning entry

`rbm_h03_bench_raw_local_snapshot` reads actual MMIO before Toyota startup
and application RAM initialization. Compile the companion without an application
profile; a diagnostic consumer includes `bench_application_profile.h` with
`RBM_H03_BENCH_PROFILE_API_ONLY=1`. The 16-byte `Lfj8H03BenchLocalRaw` result
contains two TML0 brackets, the last OEM AN2 RAM value, P1DATA, PRS1, TM0, TM1
and observation flags.

| Source | H03 evidence | Native read |
| --- | --- | --- |
| Selector AN2 | Store at `0x040370`, pointer loaded at `0x04036C` | 16 bits at `0x804BC6` |
| P1 | BL at `0x040184` calls `0x00C9B0`, containing the P1DATA address | 8 bits at `0x800701` |
| TML0 | Existing source-qualified sensor clock | 32 bits at `0x8003E0` |
| Clock registers | OEM configuration 9 / 1 / 0x31 | `0x800203`, `0x8003EB`, `0x800FEB` |

The reader holds the existing native IRQ exclusion, brackets repeated AN2,
P1 and clock-register reads with TML0, and refuses changing observations or
a span greater than 500 ticks. Unsigned subtraction admits one counter wrap;
a backwards bracket fails. Failure leaves the caller's result unchanged.
There are no application RAM accesses, ADC mailbox consumes or device writes.

Flags report whether AN2 fits 10 bits, clock registers match OEM, and TML0
moved. Stable invalid AN2, stopped TML0 and nonmatching registers remain visible
as raw observations with corresponding flags clear. These are not qualified
inputs. Repeated RAM reads do not establish ADC conversion age. P1 polarity,
independent P/N, engine load and physical clock frequency remain unqualified.

The raw path requires none of the four application providers below. Its checker
permits undefined symbols only for `lfj8_h03_mmio` and compiler `memcpy`/`memset`
helpers. This host build actually requires only `lfj8_h03_mmio`.

## Full application integration contract

The final application header includes `bench_application_profile.h` and supplies:

- `RBM_H03_BENCH_TOYOTA_PERIOD_TICKS`;
- `RBM_H03_BENCH_TOYOTA_MAX_LATENESS_TICKS`;
- `RBM_H03_BENCH_TOYOTA_WATCHDOG_TICKS`;
- `RBM_H03_BENCH_STARTUP_RANGE`;
- `RBM_H03_BENCH_STARTUP_REQUEST_1120`.

Toyota's absolute cadence is not established by H03. The known ratio is
FAST:SECONDARY:MAIN=4:2:1. No release defaults are supplied for these settings.
Serial clock bounds, bounded lateness and watchdog coverage are checked.
Numeric test values occur only in `SELFTEST_ONLY_PROFILE.h`.

The H03 phase window derives from the existing sensor profile: TOP10 nominal
500 ticks, publication every ten TOP10 periods, admitted interval 4500..5500,
phase age 5000, command age 10000 ticks. This is an engineering window in the
OEM_NOMINAL clock domain, not measured jitter. A missing full publication
is outside the window and latches the phase fault.

| Entry point | Real integration |
| --- | --- |
| `rbm_h03_bench_profile_reset_inputs` | Checks native MMIO, shared ADC and ownership, then calls `lfj8_h03_input_startup`. |
| `rbm_h03_bench_profile_sample_inputs` | Calls `lfj8_h03_input_capture`; refuses a mismatch with a nonzero previous manual gear. |
| `rbm_h03_bench_profile_capture` | Checks immutable native IO/ADC identity, then delegates to `lfj8_h03_input_capture_toyota`, which owns exclusion and source validation. |

No second selector, CAN owner, clock or input workspace is allocated.
The actual providers have explicit native symbols and static lifetime:

| Symbol | Required real supplier |
| --- | --- |
| `rbm_h03_bench_native_input_capture` | Immutable `Lfj8H03ToyotaInputCapture`, owned proposal, native binding, real `read_local`/`project_load` and age bounds. |
| `rbm_h03_bench_native_input_startup` | Immutable `Lfj8H03InputStartup`, agreed selector levels, timing and polarity. |
| `rbm_h03_bench_native_can_service` | Immutable `Lfj8H03TargetServiceConfig` using the single CAN owner, RX, TX13 and T6. |
| `rbm_h03_bench_prepare_startup_inputs` | Real GP/gear seed, owned workspace, shared DTC reset and actual `RbmU340eStartupKind`. |

Reachable supplier `59e3ae345c7678f54d055848dc967b5314074520` contains
