# TOY-06 — выход блокировки Mazda и отдельный TIO9 в H03

Проверен точный H03 `LFJ8-T-D.bin` с SHA-256 `844a11b809cda1f2ccaf90cb6a75666009487ccedd2e8190b7eb46137b855544`. Проверка сравнивает весь штатный участок ELF с исходным файлом и исполняет исходные инструкции M32R. [Проверка путей](../../targets/lfj8/check_h03_slu_output_paths.py)

## Разделение каналов

По таблице Mazda FS5A-EL блокировке гидротрансформатора соответствует дискретный Shift E (`SSE_SS5`) на 1H. В H03 ветвь `0x071AD8` обрабатывает предложение E `0x8063D8`, публикует итог по `0x8063DA`, а `0x046900 → 0x00CADC` меняет бит `0x40` порта P3. В целевом проекте 1H входит в рассматриваемую группу D/E/F для S1/S2/ST. Для исполнения U340E с пропорциональным SLU Toyota указывает собственную двухпроводную цепь регулирования давления блокировки. Для конкретного гидроблока требуется подтвердить исполнение SL или SLU. [PID Mazda FS5A-EL](https://mazdamanuals.com/Mazda/md6%200605%201107/D923-1A-22C_Ver25/esicont/srvc/html/id050221805600.html) · [Toyota U340E, P2759, AX–96–99](https://manuals.plus/m/7a70c85ec2a0d6b3000b4a6a8c2e6f0a11db29be0d4be6daba8e21b54cb50d20.pdf) · [Карта H03](../../docs/lfj8-h03-output-paths.md)

Отдельная ветвь `0x07B5B4` формирует `0x8060F0` как произведение интерполяций от напряжения питания и ATF. При выдаче `0x046954–0x0469A4` переводит значение в ширину для TIO9, а `0x00B4B4` выбирает режим P97 и записывает `TIO9RL1/RL0`. Для ширины `n` регистры получают `249−n` и `n−1`. При `n≤2` штатный код переводит P97 в GPIO и очищает выходной бит. В обычном режиме ширины от 3 до 248 используют функцию таймера. При `n=248` и сервисном режиме 4 штатная ветвь выбирает постоянный высокий GPIO. Электрический уровень на внешнем контакте и реакция силового каскада требуют измерения. [Исходная трассировка TIO9](../../docs/lfj8-slt-calibration.md#что-устанавливают-байты-h03)

## Результаты M32R

| Сценарий | Shift E / P31 | TIO9 / P97 |
| --- | --- | --- |
| Переключение запроса E при 13,59375 В и 80 °C | 0→1 | PWM, ширина 66 в обоих вызовах |
| Общий штатный запрет `0x8063F2` при удержанном запросе E | 0 | PWM, ширина 66 |
| Флаг P0773 при активной сервисной заявке E | 0, сервисная подстановка уступает отказу | PWM, ширина 66 |
| 8,046875 В и 80 °C | 0 | PWM, ширина 108 |
| 8,046875 В и −40 °C | 0 | PWM, ширина 83 |

Прошли 18 сценариев нового прогона, шесть сценариев штатного арбитра и 59 сценариев мониторов выходов. Отдельная проверка текущего проектного запрета подтвердила сохранение регистров порта 9. Следовательно, для возможного использования P97 нужно доказать отдельное снятие PWM и обесточивание каскада при отказе. Штатный общий запрет этого действия в проверенном пути не выполняет. [Мониторы и проектный запрет](../../targets/lfj8/check_h03_slt_fault.py)

```powershell
python -B targets/lfj8/check_h03_slu_output_paths.py --base $h03 --gcc $m32rGcc
python -B targets/lfj8/check_h03_shift_arbiter.py --base $h03 --gcc $m32rGcc
python -B targets/lfj8/check_h03_slt_fault.py --base $h03 --gcc $m32rGcc
```

Для подключения SLU остаётся физически проследить P97 от MCU до нагрузки, подтвердить полярность и двухпроводный каскад либо установить отдельный драйвер. Затем нужно измерить связь команды с током, скольжение при удержании и снятие блокировки при отзыве. Полный снимок входов SLU остаётся отдельным условием.
