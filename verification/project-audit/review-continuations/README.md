- `unit-tests.txt`: весь Python-набор — 129 проверок, без пропусков; 29 из них проверяют координацию через настоящий временный Git-сервер.

- `migration-preview.json`: только чтение реальной доски. Все 32 записи сохранены, 31 review перенесён в отдельную очередь; единственный действующий резерв сохранён. Это предварительная проверка, не свидетельство публикации миграции.

Review освобождает задачу, файлы и ветку. Сданный SHA остаётся в очереди до точной приёмки. Новый исполнитель включает необходимые SHA в свою ветку и получает новый claim. После миграции все чаты должны использовать tools/task_coordination.py из актуальной main; старый клиент не может перезаписать формат 2.

Прошлые проверки прошивок и незавершённые требования приведены в ../2026-11-21-integration.json. Эти проверки не означают выпуск готовых BIN.
