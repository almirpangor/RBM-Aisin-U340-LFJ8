# REL-01 — распознавание проверочных BIN по отчётам и манифестам

База `5e3ac748843f3a7326ad070b47f6c3b137e32289`.

`package_workset.py --firmware-pair` теперь сверяет SHA‑256 кандидатов также с отчётами в `verification/` зафиксированного коммита и с манифестом рядом с каждым входным BIN. Он использует только запись с явным статусом `OFFLINE_ONLY` и поля идентификатора образа `sha256`, `bosch_sha256` или `image_sha256`. Для сквозных отчётов поддерживается вложенная запись `bosch_candidate_frame_probe` с собственным статусом. Хеши исходника и базовой прошивки не принимаются за хеш проверочного образа.

Режим ZIP с доказательствами сохраняет возможность приложить проверочный образ. Режим пары BIN останавливается до записи ZIP при совпадении SHA‑256. Раздельные признаки сборки, модели и оборудования сохраняются в манифесте.

## Проверки

- **Регрессия упаковщика.** До изменения четыре представления отчёта и один локальный манифест позволяли собрать тестовый пакет с переименованным OFFLINE_ONLY. После изменения прошли все шесть тестов упаковщика, включая сохранение детерминизма и проверку на ложное совпадение с хешем базы.
- **Проверочный образ Bosch.** Закреплённые R4/S04 дали компактный профиль с передачей RPM/ОЖ, SHA‑256 `9f0c5f50790338d3dee890ac8ded709d72e367a26bb0ad8a66386ce648130c46`, статус `OFFLINE_ONLY_NOT_HARDWARE_TESTED`. Этого SHA не было среди известных образов в архиве исходного Git-коммита. После переименования BIN упаковщик отклонил его по локальному манифесту. Для проверки комплекта вторую роль заполнял синтетический файл требуемого размера. ZIP пары не создан. Два ZIP доказательств с реальным проверочным Bosch имели одинаковый SHA‑256, содержимое образа сверено после упаковки.
- **Общий прогон.** `tools/build_pc_checks.py` прошёл все 37 шагов, включая 116 тестов unittest с закреплённым S03. Проверка происхождения подтвердила ТЗ, закреплённые R1/S01–S04 и точный H03. Исторические S05/S06 в этой проверке пропущены.
- **Общий аудит.** `project_status.py --check` прошёл на базе. Изменённые файлы упаковщика и его теста требуют обновления общего снимка при интеграции.

Целевой комплект двух BIN остаётся открытым до окончания привязок H03, арбитража Bosch и аппаратных проверок.
