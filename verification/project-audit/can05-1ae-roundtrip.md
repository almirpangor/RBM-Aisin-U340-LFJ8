# CAN-05 — сквозная проверка 0x1AE в модели ПК

База проекта: `264f2498002dbd7ee0d0ca8723ccbb88632ec11d`. Компилятор ПК: Zig 0.17.1.

## Модель ПК

Тест напрямую передаёт кадры из `lfj8_pack_1ae_with_counter` в `bosch_chery_torque_receive`. Квалификатор берётся из Git-объектов R3 по коммиту, закреплённому в `data/sources.json` (`7585de6945b4b6b3ef381c6062070a5f417cf588`).

```powershell
python -B tests/test_chery_1ae_roundtrip.py --donor-repo $r3 --cc $zig
```

- PASS: все 65 536 пар байтов 1 и 4, переход счётчика 7 → 0, целостность контрольного поля и независимая недостоверность каждого операнда при FF. При FF в обоих каналах снимок пуст.
- PASS: пропуск одного кадра, отклонение повтора и повреждённого контрольного поля, восстановление после корректного кадра, сброс счётчика при снятии разрешения и повторная синхронизация после истечения срока. Числа −2621 и +2621 для 40/60 являются выходами модели квалификации. Срок из восьми тиков используется только в тесте.
- PASS: `python -B tools/build_pc_checks.py --cc $zig --out local/pc-checks`, все 33 шага, включая 59 тестов unittest и сквозную модель с компонентами C.

## Проверочная сборка Bosch и модель ST10

- PASS: сборка по команде BOSCH карточки CAN-05, профиль no-cruise/compact, 51 запись контрольных сумм. SHA-256 образа OFFLINE_ONLY `bd0afefa40dfd1ea82e647ea5af7e64e2f652c27ccc5c3b91a986224fd77ec79`.
- PASS: `verify_ordinary_model_field.py --compact`, 56 сценариев допуска режима, 65 536 случаев кодирования штатных полей, 64 сценария квалификации кадра, 6 сценариев изменения входов и 3 сценария задержки IF1. Для `--model` использован `tools/c167_subset.py` из R3 `7585de6`, с проверкой закреплённого SHA-256 в `verify.py`. В R2 `39bf857` этого файла нет.
- Модель ST10 проверяет существующую сборку Bosch. Новый тест приёмника 0x1AE выполняется отдельно на ПК.

## Интеграция и оборудование

`project_status.py --check` на исходном коммите прошёл. На рабочей ветке проверка отмечает два новых файла теста, отсутствующие в активном общем снимке. При принятии порции интегратору нужно включить их в обновлённый снимок аудита и привязать отчёт к CAN-05.
