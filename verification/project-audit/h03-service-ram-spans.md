# H03-04 — проверка адресных интервалов сервисным монитором

Основа `952658bff619a36f4921d637a2f0efae621f416d`. Проверены исходные инструкции H03 `LFJ8-T-D.bin` с SHA-256 `844a11b809cda1f2ccaf90cb6a75666009487ccedd2e8190b7eb46137b855544` и актуальная раскладка кандидатов RAM из STORAGE. [Карта памяти](../e4m3-can-9e1c/h03-storage.json)

Верификатор с `--storage-report` сверяет идентификатор H03, размеры, границы и непересечение блоков, затем делит блоки на непересекающиеся интервалы до 255 байт. Каждый интервал отдельно проверяется штатной функцией допуска `0x003528` в симуляторе GNU M32R. Дополнительные восемь случаев сравнивают граничные интервалы вокруг `[0x808578, 0x808DB4)`. Снизу условие исходной функции для разрешения строгое по `start + count`. Сверху допустимым оказался старт ровно на верхней границе. [Верификатор](../../targets/lfj8/check_h03_service_isolation.py)

| Блок | Кандидат RAM | Байты | Допущенные интервалы |
| --- | --- | ---: | ---: |
| Управление | `[0x806B40, 0x806F70)` | 1072 | 5 из 5 |
| Связь | `[0x808E40, 0x80902C)` | 492 | 2 из 2 |
| Рабочие снимки | `[0x80902C, 0x80935C)` | 816 | 4 из 4 |

Штатная проверка допускает интервалы, покрывающие все 2380 байт. Эти кандидаты требуют отдельного исключения прямых и отложенных сервисных записей до передачи RAM приложению. Для отложенного пути остаётся проверить допуск по всему диапазону и завершение либо отзыв начатой операции. В этом прогоне транспорт, процедуры записи и физический 9E1C не выполнялись. [Разбор сервисных путей](../../docs/lfj8-h03-service-isolation.md)

## Проверки

- **STORAGE.** ABI M32R и адресная модель совпали с блоками из `main`. Пройдены шесть исходных инициализаций OEM с контрольными байтами.
- **Модель допуска.** Пройдены 35 сценариев. 16 прежних проверок дали прежний JSON, восемь новых проверили границы исключения, 11 покрыли обновлённые кандидаты. Раздельно отклонены планы с другим SHA H03, неверным размером, пересечением блоков или выходом из RAM.
- **M32R.** Собраны перемещаемые ELF контроллера и моста. Прошли 17 компонентных прогонов и сквозная модель с сохранёнными кадрами Bosch.
- **NATIVE.** Прошли 16 сценариев диспетчеризации и 15 прогонов фаз на исходных инструкциях H03 в симуляторе.
- **Python.** В общем наборе прошли 69 тестов. Проверка таблицы с исходным образом S03 была пропущена без `RBM_S03` и прошла отдельным запуском с донором из зафиксированного Git blob.

```powershell
python -B targets/lfj8/check_h03_storage.py --base $h03 --gcc $m32rGcc --out local/audit/h03-storage.json
python -B targets/lfj8/check_h03_service_isolation.py --base $h03 --gcc $m32rGcc --storage-report local/audit/h03-storage.json > local/audit/h03-service-spans.json
```
