# TOY-03 — допуск независимого P/N для снимка диапазона

База ветки — `main ae393e8`. Статический и нативный прогоны
использовали штатный LFJ8-18-9E1C H03 с SHA-256
`844a11b809cda1f2ccaf90cb6a75666009487ccedd2e8190b7eb46137b855544`.

В `targets/lfj8/lfj8_h03_range_pn.{c,h}` добавлен
`lfj8_h03_range_qualify_pn`. Он принимает уровень уже
нормализованного независимого контакта и подтверждённое положение
AN2. Оба отсчёта должны принадлежать текущему поколению часов.
Функция проверяет давность и расстояние между захватами, а также
согласие контакта с определённым положением P/N. Границы времени
передаёт вызывающий код. Возврат при отказе очищает выход.

При успехе результат имеет тип `Lfj8H03RangeBit` и несёт более
старую из двух меток. Это позволяет передавать его в
`Lfj8H03RangeInputs.range_5722[2]` перед штатной сборкой снимка.
Остальные четыре операнда проверяются существующим потребителем.
Отдельного статического состояния и записей в периферию нет.

## Проверки

- `check_h03_range_pnp.py` по-прежнему выполняет исходные инструкции
  H03. Прошли все 1024 значения AN2, 20 вызовов штатной
  классификации и четыре вызова с подстановкой напряжения только
  в симуляторе. Перед запуском секция штатной ROM сравнивается с
  утверждённой основой побайтно.
- `test_lfj8_h03_range_pn.c` теперь запускается в том же M32R ELF.
  Проверены 12 сочетаний шести диапазонов с обоими уровнями
  контакта, смена старейшего отсчёта, переход часов через ноль,
  точные границы давности и рассогласования. Неизвестный
  селектор, старое поколение, будущая метка, отсутствующий или
  невалидный контакт и расходящиеся отсчёты отклоняются.
  Нативный тест передаёт результат в `lfj8_h03_range_snapshot`
  и проверяет истечение срока по старейшей метке.
- `check_h03_selector_adc.py` повторил пять сравнений штатного
  и кандидатного захвата AN2. Совпали состояние CPU, аккумулятор,
  штатные данные и продолжение пути H03.
- Набор `check_integrated_h03.py --suite components` прошёл
  все восемь групп. Размер функции в объекте M32R с `-Os`
  составил 236 байт без учёта уже используемого `memset`.

```powershell
python -B targets/lfj8/check_h03_range_pnp.py --base $h03 --gcc $gcc
python -B targets/lfj8/check_h03_selector_adc.py --base $h03 --gcc $gcc
python -B tools/check_integrated_h03.py --suite components --base $h03 --gcc $gcc --controller $controller --out local/toy03-pn/components
```

Открыты физический источник на целевом жгуте, его полярность,
измеренные пределы возраста и рассогласования, вызов из владельца
foreground и окончательная реакция P0705. Тестовые уровни и интервалы
относятся к симулятору. Проверка на физическом блоке и установка в BIN
не выполнялись.

`project_status.py --check` отмечает новые файлы и изменённую
проверку. Общий снимок аудита обновляет интегратор.
