# H03-03 — общий снимок датчиков в штатном foreground

База ветки — `760628b`. Предыдущие H03-02 и H03-03 уже входят в
опубликованную `main`. Исходный H03 LFJ8-T-D.bin проверен по SHA-256
`844a11b809cda1f2ccaf90cb6a75666009487ccedd2e8190b7eb46137b855544`.

Штатный вызов из `0x00816C` сначала исполняет OEM-сбор входов, затем
владелец приложения забирает допущенную фазу. Под общей блокировкой он
читает один снимок S51/S83/ATF, передаёт его в `take_toyota` и в
`service_phase` этой фазы. Оба потребителя получают один экземпляр
с исходными отметками и признаками достоверности каждого канала.
Потеря общей квалификации, невалидная конфигурация или несогласованные
чтения закрывают допуск через штатный отказ приложения. Отсутствие
импульсов не считается остановкой.

Владелец эпохи TML0/TML1 — приложение H03. При входе через холодный
шлюз, перед повторным стартом и при отказе оно отзывает квалификацию
и сбрасывает историю. После инициализации оно открывает эпоху только
при подтверждении платформой обеих частот 1 МГц и совпадении штатных
регистров. Перед будущей перенастройкой или перезапуском счётчиков
платформа должна закрыть шлюз. До установки IRQ-врезок целевая
платформа должна получить и удерживать владение RAM и гарантировать
очистку допуска до первого захвата.

## Проверки M32R

`check_h03_phase_boot.py` использует OEM-диспетчер `0x003DE0–0x003E40`,
оба обработчика захвата, штатные процедуры маскирования IRQ и выход
через `RTE`. Вход через TRAP и таблица IVECT в RAM моделируют
источник IRQ. У каждой врезки проверены сохранение R0–R15, активных
битов PSW, наблюдаемых частей ACC, курсора отдельного стека PSW,
штатная запись метки и сброс флага периферии. Входы OEM-агрегаторов
`0x046794` и `0x0467A0` замещены возвратом.

В двух режимах проверки пройдены 38 сценариев, включая 80 возвратов
из IRQ с совпадающим контекстом. Подтверждены 14 первых снимков с
обоими свежими периодами и публикацией ATF. Варианты с отличающимся
`TML1CR` при старте, изменением `TML1CR` во время работы и
недопустимым тайм-аутом не вызвали потребителей.
После тёплого старта отброшены прежние отсчёты всех трёх каналов.
Отдельный `check_h03_sensor_native.py` прошёл для штатного и
кандидатного ELF, включая перенос TML0, отзыв и повторный допуск.

Связанный тестовый код проверен в пустом окне
`[0x020000, 0x030000)` исходного H03. Из ELF проверены машинные
адреса переходов из `0x008100`, `0x00814C`, `0x008150`,
`0x00816C`, `0x040424`, `0x00AA0C` и `0x00AA70`. Оба места
продолжения `0x00AA10` и `0x00AA74` вошли в адресную проверку.
В сценарии `owned` с начальным OEM максимумом 11 обёртки
foreground, S51 и S83 связаны по `0x0202A0`, `0x021C80` и
`0x021CCC`. SHA-256 машинного отчёта `phase-boot.json` —
`586211513b097b7b34a578b20b39e3e2fbfa4c37f0a947f7f49061d556593532`.

Базовая сборка `check_h03_link.py` прошла 18 компонентных проверок
M32R с воспроизведением сохранённой трассы Bosch. Набор INTEGRATION3
native прошёл все 17 групп, включая расширенный `phase-boot`.
Для базового состава без привязок MEMORY4 повторил
`PASS_ADDRESS_MODEL_ONLY` с объёмом Flash 82 812 байт и шестью
сценариями по адресам размещения.

На ПК прошли 37 этапов. Из 113 тестов unittest 112 прошли, один
пропущен из-за отсутствия `RBM_S03`. Сквозная модель на ПК дала
`PASS_OFFLINE_ONLY`.

## Границы

Полный состав `padding-candidate --with-bindings` остановился на
`FAIL_BINDINGS` с теми же семью отсутствующими определениями целевой
платформы. Остались реальные часы, тайм-ауты и RAM, однозначное
распознавание остановки, привязка физических входов к Toyota и CAN,
итоговая карта с политикой Virtual Flash и максимальный вложенный стек.
Успешный тест использует тестовые MMIO и callbacks симулятора M32R.
Проверки на физическом блоке и создание BIN не выполнялись.
На ветке `project_status.py --check` указывает на четыре изменённых
файла. Общий снимок аудита обновляет интегратор после объединения.

## Воспроизведение

```powershell
python -B targets/lfj8/check_h03_phase_boot.py --base $h03 --gcc $gcc --out local/h03-03/phase-boot.json
python -B targets/lfj8/check_h03_sensor_native.py --base $h03 --gcc $gcc --out local/h03-03/native-sensor
python -B tools/check_integrated_h03.py --suite native --base $h03 --gcc $gcc --controller $controller --out local/h03-03/integration-native
python -B tools/check_h03_image_layout.py --base $h03 --gcc $gcc --controller $controller --bridge $bridge --profile padding-candidate --with-bindings --out local/h03-03/layout-full
```
