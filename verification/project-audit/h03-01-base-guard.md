# H03-01 — строгая проверка утверждённого исходника

База — `b2ca79d006426a9839d64e8553cd81bf71953fe9`.

`tools/inspect_lfj8_tcm.py` поддерживает режим `--require-h03`.
Успех требует внутреннего номера `LFJ8-18-9E1C`, полного размера
и SHA-256 из записи H03 в реестре. В JSON отдельно видны совпадение
внутреннего номера (`matches_expected_id`) и базы (`matches_h03`).

```powershell
python -B tools/inspect_lfj8_tcm.py $h03 --require-h03
python -B -m unittest discover -s tests -p test_inspect_lfj8_tcm.py -v
```

Код 0 означает совпадение, 1 — расхождение, 2 — ошибку ввода
или чтения. Обычный режим по-прежнему позволяет исследовать варианты
LFJ8 по встроенному номеру через `--expect`.

## Проверки

- Локальный утверждённый H03 принят. Размер 524 288 байт,
  ПО `LFJ8TC000LFXA0A0`, SHA-256
  `844a11b809cda1f2ccaf90cb6a75666009487ccedd2e8190b7eb46137b855544`.
- Локальная контрольная копия с изменённым байтом по `0x020000`
  сохранила тот же внутренний ID и размер. Строгая проверка вернула 1
  и `matches_h03=false`. Исходный H03 читался без записи.
- Два теста прошли, включая неполный образ, другой вариант номера,
  неверный дайджест и коды завершения CLI.
- SOURCES сверил ТЗ, S01–S04 по Git blob и SHA-256, а также H03.
  Исторические S05/S06 пропущены. [Команда SOURCES](../../docs/project-map.md#check-sources)

Общий снимок аудита требует актуализации для скрипта и теста.
Проверка относится к идентичности файла. Изменений прошивки и
испытаний на блоке в этой порции не было.
