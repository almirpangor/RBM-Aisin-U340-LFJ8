# REL-01 — идентификация образов при упаковке двух BIN

База проверки — `ae393e852fd8e110892c6725f219f3e43585d33c`.

В режиме `--firmware-pair` упаковщик проверяет файлы перед записью ZIP. SHA-256 образов сравниваются с реестром исходников и аудитом E4M3 из коммита `source_commit`. Это исключает переименованные исходные H03 и S04, доноры и предыдущие версии Bosch из аудита. Проверка `OFFLINE_ONLY` продолжает использовать сохранённые отчёты и локальный манифест сборки. Архив доказательств без `--firmware-pair` сохраняет прежний режим.

Для TCM переиспользуется разбор встроенного `LFJ8-18-9E1C` по смещению `0x031033`. Загрузчик H03 ожидает `5AA5` по `0x008000` и `A55A` по `0x07FFFE`. Для Bosch проверяется строка платформы `ME7.9.71/720/4415EN.2/` по `0x0A844A`. Она совпала на закреплённом S04 и компактном проверочном образе Bosch. [Разбор запуска H03](../../docs/lfj8-9e1c-base.md) · [Реестр исходников](../../data/sources.json) · [Аудит E4M3](../../data/e4m3-diff.json)

## Проверка на ПК

- Девять тестов `python -B -m unittest discover -s tests -p test_package_workset.py -v`. Проверены исходники H03/S04, предыдущий E4M2, неверная ревизия TCM, обе контрольные метки запуска, неверный идентификатор Bosch, воспроизводимый ZIP на тестовых данных и прежние проверки `OFFLINE_ONLY`. На прежней реализации регрессионные тесты обнаружили приём исходников и образа с неверной меткой.
- Прямой вызов `tools/package_workset.py --firmware-pair` с настоящим Git-архивом базового коммита отклонил переименованные H03, S04, S02, REV8, компактный Bosch `OFFLINE_ONLY` и полноразмерный нулевой образ Bosch. В каждом случае ZIP отсутствовал.
- `tools/verify_sources.py` проверил закреплённые R1/R3/R4, ТЗ, S01–S04 и H03. Исторические S05/S06 в этот прогон не входили.
- `tools/project_status.py --check` прошёл на чистой базе. Снимок кода после объединения обновляет интегратор.
- Полный набор `tools/build_pc_checks.py` прошёл 41 этапов на Zig 0.13.0, включая 123 теста unittest. Сквозная программная проверка подтвердила приём скорости моделью компактного Bosch и вернула `PASS_OFFLINE_ONLY`.

## Границы проверки

Поля образа и SHA-256 подтверждают перечисленные признаки и исключают известные исходники. Подтверждение происхождения конкретной сборки, её поведения в модели и испытания на оборудовании остаются отдельными доказательствами. Целевой код в этой порции не изменялся. В текущей базе расширенная компоновка H03 ожидает `rbm_h03_application_binding` и `rbm_h03_sensor_config`. Bosch по-прежнему имеет статус `OFFLINE_ONLY`. Выпуск двух BIN остаётся открытым.
