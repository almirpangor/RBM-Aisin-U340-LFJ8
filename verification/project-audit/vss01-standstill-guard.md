# VSS-01 — подтверждение остановки после первого фронта S51

База `760628bd249b19051339403f5663e78187d12a9a`. Изменение касается скорости в штатном планировщике `0x1AE`.

Первый фронт S51 начинает захват, но ещё не даёт интервал. Раньше планировщик трактовал результат как недоступный и затем заменял его нулём при установленном признаке остановки. Новый сценарий в `host_check.c` воспроизвёл ложный ноль до исправления.

Теперь подтверждение остановки учитывается внутри той же критической секции, где читается TML0CT и проверяется состояние захвата. Передача нулевой скорости требует независимого действующего подтверждения со значением 1, допустимого срока давности и отсутствия свежего фронта S51. Пока интервал не готов, пришедший фронт приводит к `0xFFFF`. После измерения интервала передаётся рассчитанная скорость. Обычный API снимка для остальных вызовов сохранён.

## Проверки

- **Модель на ПК.** `targets/lfj8/build.py --zig` прошёл целевую проверку. В сценарии CAN отправляет `0x0000` при подтверждённой остановке, `0xFFFF` после первого фронта и `0x1770` после второго фронта через переход TML0CT через ноль. Также проверены истечение срока без подтверждённой остановки, недопустимое значение подтверждения и нулевой срок давности. Частота, окружность и интервал в сценарии являются тестовыми.
- **Полный набор на ПК.** `tools/build_pc_checks.py` прошёл все 37 шагов, включая 113 тестов unittest с закреплённым S03.
- **M32R.** Объекты ELF BE для неизменённого H03 собраны с GCC 4.8.0. `check_h03_link.py` с трассой Bosch прошёл 18 компонентных прогонов, включая новый сценарий. Отдельный набор `--suite components` прошёл шесть проверок, включая арифметику VSS. Компоновка `prefix-candidate --cpu-test` прошла шесть сценариев исполнения по рассчитанным адресам со статусом `PASS_ADDRESS_MODEL_ONLY`. Запас окон в этой модели составил 848 и 0 байт.
- **Проверочный Bosch.** Обычный компактный образ сохранил SHA-256 `bd0afefa40dfd1ea82e647ea5af7e64e2f652c27ccc5c3b91a986224fd77ec79` и прошёл модель ST10 со статусом `PASS_OFFLINE_ONLY`.
- **Общий аудит.** `project_status.py --check` прошёл на базе. Пять изменённых файлов кода и тестов требуют обновления общего снимка при объединении.

В машине остаётся подтвердить источник независимого признака остановки, время и калибровку S51, а также подключение расчёта к штатному приложению H03. Испытаний на оборудовании не было.
