# H03-02 — единый допуск часов для S51, S83 и ATF

База — `5e3ac74`, штатный LFJ8-18-9E1C H03 с SHA-256
`844a11b809cda1f2ccaf90cb6a75666009487ccedd2e8190b7eb46137b855544`.

На исходном коде тест M32R получил действительную температуру из
`lfj8_h03_atf_target_snapshot` при изменённом `TML1CR`. Штатный
поставщик времени ATF проверял делитель и один бит `TML0CR`, а
захваты S51/S83 сверяли конфигурацию обоих таймеров целиком.

Теперь все три канала используют одну проверку под блокировкой IRQ.
Для допуска нужны `PRS1=9`, `TML0CR=0x01` и `TML1CR=0x31`.
Первый вызов, увидевший расхождение, отзывает общий допуск. При
следующем захвате или чтении общего снимка адаптер сбрасывает
историю эпохи. OEM-записи захвата продолжаются. Восстановление
битов регистров само по себе не возвращает разрешение на публикацию.
Владелец часов открывает новую эпоху явным `rbm_h03_sensor_clock_rebase`
после независимого подтверждения частот.

## Проверки M32R

- `check_h03_sensor_native.py` прошёл на штатном и кандидатном ELF.
  Проверены отзыв со стороны ATF при изменении `TML1CR`, отказ по
  `TML0CR=0x11` при установленном бите выбора Clock Bus 1, сохранение
  записи S51 и отбрасывание прежней истории после восстановления
  регистров. В новой эпохе старые периоды и температура недоступны.
  SHA-256 отчёта `sensor-native.json` —
  `3aaf5d6659d410ea61f8d3a59fda317831a86cb144897b9c21d61bab07b1a80c`.
- `check_h03_atf_native.py` прошёл 11 пар штатных и кандидатных
  сценариев. Наблюдаемые максимумы записи в стек с обёртками
  составили 100/128/80 байт для AN1, вычисления температуры и
  чтения снимка. Эти значения включают кадры тестового кода.
  Полный вложенный стек остаётся открытым.
- INTEGRATION3 native прошёл все 17 групп на базе `5e3ac74`.
- Совместный прогон с H03-03 `391a5514f65fddb1041cfd7b7ee8018c10110c30`
  выполнен в отдельной тестовой копии. `check_h03_phase_boot.py`
  прошёл 38 сценариев, включая 80 проверенных возвратов из IRQ и
  14 первых снимков S51/S83/ATF в штатном foreground. SHA-256
  отчёта `phase-boot-joint.json` —
  `14c087278930d710ca275fd4835c8fd4ecf13425e63c06555d6b4b03e3364ad1`.

## Оставшиеся привязки

Расширенная компоновка с `--with-bindings` дала `FAIL_BINDINGS`
с прежними семью неопределёнными символами платформы. Частоту
1 МГц и политику обнаружения сброса счётчика при неизменных регистрах
требуется подтвердить на целевом блоке. Требуются итоговое размещение,
владение RAM и проверка реальных сигналов. Проверка блока и создание
BIN не выполнялись.

`project_status.py --check` на ветке отмечает пять файлов,
изменённых после общего снимка. Интегратор обновляет снимок при
объединении.

```powershell
python -B targets/lfj8/check_h03_sensor_native.py --base $h03 --gcc $gcc --out local/h03-02-clock/native-sensor
python -B tools/check_integrated_h03.py --suite native --base $h03 --gcc $gcc --controller $controller --out local/h03-02-clock/native
python -B tools/check_h03_image_layout.py --base $h03 --gcc $gcc --controller $controller --bridge $bridge --profile padding-candidate --with-bindings --out local/h03-02-clock/layout-full
```
