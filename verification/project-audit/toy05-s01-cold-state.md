# Начальное состояние Toyota: перенос холодной ветви

21.11.2026, база `55b9a240338ef1cf58da6218e8634450373b9f92`. Добавлена `rbm_u340e_runtime_prepare_s01_cold` в [runtime](../../controller/src/rbm_u340e_runtime.c). Она переносит принадлежащую нашему runtime часть S01 `0540B0/0545E0/055104/055730` и подготовки фильтра из закреплённого R3. Штатные донорские файлы не изменены.

Процедура устанавливает начальные коды передач, счётчики, признаки отсутствующих периодов и историю скорости, снимает только заданные биты флагов. Она проверяет допустимость всех записей до изменения состояния, использует существующую рабочую область и не выделяет постоянную RAM. Общие поля передачи и гидравлики остаются согласованными.

Это **часть запуска**, а не готовые `rbm_h03_target_startup_gear/gp`: сначала владелец обязан установить остальные входы и состояние, подтвердить применимость холодной ветви, затем вызвать функцию до восстановления адаптаций и допуска заданий/выходов. Из 828 принадлежащих runtime байт в проверке меняются 143, остальные 685 сохраняются. Среди изменяемых есть три маскируемых флага; их посторонние биты тоже сохраняются. Подставлять нули вместо этих исходных данных нельзя.

## Выполненные проверки

- 258 сравнений всех 828 байт с неизменённым C-переносом R3; для каждого случая дополнительно проверены повторный вызов и согласованность общего/рабочего состояния. Источники и исходный отчёт сверены по SHA. R3 ранее сравнил холодную ветвь с оригинальным V850 в 256 случаях; этот прогон V850 сейчас не повторялся.
- Проверки контроллера на ПК и M32R: все 256 сочетаний флагов, сохранение независимых входов, отсутствующие периоды, отклонение NULL/неинициализированного/перекрывающегося состояния. Прежние проверки контроллера, 292 переноса GP и пять снимков гидравлики прошли.
- Шесть групп CPU с неизменёнными байтами размещённого ядра, включая новую процедуру через runtime-тесты, прошли. Это адресная модель, не прошиваемый образ.
- Пересобраны контроллер и мост, обновлён инвентарь RAM и измерена композиция с реальным application binding и явно тестовым профилем.

## Память и остающийся отказ

Удерживаемое ядро — 84904 байта, известная композиция с binding/нижним BasicCAN — 101460 байт: увеличение на 434. Постоянная RAM — прежние 2728 + 4 байта указателя IRQ. Все дополнительные будущие контексты и окончательный стек сюда ещё не входят.

Список десяти неопределённых символов **не сократился**. Новая функция — подтверждённая часть реализации поставщика начального состояния; она не создаёт полноценный стартовый снимок и автоматически не подключена к запуску. Остались реальные поставщики RAM, часов, CAN/контекста двигателя, полного снимка Toyota, общего запуска/обслуживания, силовых операций и конфигурация датчиков. Кроме них остаются шкалы нагрузки Bosch→Toyota, физическая калибровка SLT/SLU, NVM и установка всех переходов. Bosch не изменён и остаётся OFFLINE_ONLY. Два рабочих BIN не созданы.
