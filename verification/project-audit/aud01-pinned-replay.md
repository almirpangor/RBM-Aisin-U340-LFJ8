# AUD-01 — повтор трассы E4M3 из одной Git-ревизии

База — `b2ca79d006426a9839d64e8553cd81bf71953fe9`.

Ранее трасса читалась из закреплённого коммита R4, а сборщик, исходный
образ и модель ST10 загружались из рабочей копии. В клоне Git без
checkout команда останавливалась при чтении образа сборщика.
Теперь утилита извлекает каталог `development/E4M3/engine` из
`dc6b4f08a24e648d3d0dab986c1765abb6fd294a` во временный каталог.
Для трассы используется тот же коммит. Ревизия включается в JSON
выходного отчёта, а перед повтором проверяется воспроизводимость
входного Bosch-образа.

```powershell
python -B targets/bosch/replay_e4m3_torque.py --repo $r4 --image $image
```

## Результаты

- В клоне R4 без checkout прошли оба компактных образа
  `OFFLINE_ONLY`: профиль обоих полей и ordinary. Все поля прежних
  отчётов совпали. Новое поле `r4_commit` фиксирует ревизию.
  [Первый профиль](../e4m3-can-9e1c/torque-replay.json) · [Ordinary](../e4m3-can-9e1c/ordinary-model/torque-replay.json)
- В каждом прогоне проверены CRC 3256 кадров исторической записи.
  В модели поданы 26 команд, оба токена дали полное снижение по
  испытательному профилю и вернулись к нулю.
- В отдельной проверке ordinary прошли 56 проверок штатного режима,
  65 536 сравнений кодирования, 64 сценария полей и сверка 51
  записи контрольной целостности. Результат — `PASS_OFFLINE_ONLY`.
- SOURCES прошёл для ТЗ, S01–S04 и H03. Исторические S05/S06
  пропущены. `project_status.py --check` указал изменённый скрипт
  для актуализации общего снимка интегратором.

Использована историческая запись протокола RB `0x5E8/0x5E9` и
симулятор ST10. Аппаратная проверка новой пары TCM/ECU остаётся
открытой в ECU-02.
