## Реализация

- `controller/build_target.py`: необязательный параметр API `memory_model` и CLI
  `--memory-model medium|small`. Флаги создаются для конкретного вызова; глобальный
  `ARCHITECTURE` не меняется. Модель по умолчанию осталась `medium`.
- `targets/lfj8/build.py`: такой же параметр API и CLI
  `--m32r-memory-model medium|small`. Выбранная модель применяется при компиляции
  и объединении M32R-объектов и попадает в обычный манифест сборки.
  Неподходящая архитектура/модель отвергается до запуска компилятора.
- `tools/check_integrated_h03.py`: `--small-model` вызывает оба штатных сборщика.
  Убраны подмена функций сборщика и ручное исправление полей манифеста. Теперь
  мост получает полный обычный список исходников и проверку выбранного H03.
- После успешного или ошибочного расширенного прогона восстанавливаются
  `TARGET`, списки исходников/корней и `check_split_layout`. Входной объект
  аргументов не изменяется. Повторный прогон не накапливает корни и не наследует
  настройки `small` от предыдущего.

Пути вызова: прежний `expanded(args)` → изолированная конфигурация →
`expanded_check`; для `small` перед проверкой выполняется `rebuild_objects`.
Условия отказа, адресные ограничения, квалификация выходов и упаковка BIN
этими изменениями не ослаблены.

## Следующий воспроизводимый шаг

На среде с доступным точным H03 и запускающимся M32R GCC, для каждой модели:

```powershell
python -B controller/build_target.py m32r --cc $gcc --memory-model medium --out local/continue/medium/controller
python -B targets/lfj8/build.py --m32r-cc $gcc --base-9e1c $h03 --m32r-memory-model medium --output local/continue/medium/bridge
```

Для второго состава заменить `medium` на `small` в параметрах и каталогах.
Затем повторить общую проверку размещения с соответствующим `--memory-model`
и обоими пересобранными объектами. Для прежней расширенной гипотезы оставить
`--small-model`: она теперь использует эти же публичные пути сборки.

Отдельно остаются действительные профили/поставщики, полная компоновка,
квалификация памяти, сериализация TCM и согласованный выпуск Bosch. Новые
расходы Flash/RAM/стека не измерены: новый целевой объект не собран.
`build_verified:false`, `hardware_verified:false`, `bench_pair_ready:false`.
Два рабочих BIN этой порцией не выпущены; блоки не прошивались.
