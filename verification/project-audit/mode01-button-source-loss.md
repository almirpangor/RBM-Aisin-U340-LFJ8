# MODE-01 — отзыв допуска кнопок после сообщения об отказе

База `main` — `5e3ac748843f3a7326ad070b47f6c3b137e32289`.

## Регрессия и изменение

В Tiptronic при подтверждённом D удерживаемый `+` мог превратиться
в заявку на третью передачу после явного отказа источника кнопок.
Фильтр игнорировал отказ, когда его время совпадало с последним
отсчётом, и продолжал подтверждать нажатие по старому состоянию
дребезга. На исходном коде сквозной тест ПК воспроизвёл заявку.

Фильтр теперь сбрасывает допуск и кандидат дребезга при явном
отказе источника или некорректном значении снимка, включая
сбой его времени. Метка последнего отсчёта продвигается только
по прежним правилам давности и порядка. Повторные, просроченные
и будущие корректные отсчёты по-прежнему игнорируются. Допуск
восстанавливается после устойчивого отпускания, следующее
подтверждённое нажатие снова может сформировать заявку. Состояния
Tiptronic и Overdrive сохраняются. В обвязке H03 действующая
проверка `buttons->armed` отзывает снимок заявки на время
восстановления.

## Проверки

- Общий прогон на ПК прошёл все 37 шагов, включая 113 тестов
  Python и сквозной сценарий с компонентами C.
- Сквозной тест программного фильтра прошёл 15 сценариев
  на ПК и M32R. Сочетаются явный отказ, неправильное значение
  `valid` и недопустимые биты кнопок с пятью вариантами времени
  около переполнения счётчика. Проверяются повторная, переставленная,
  просроченная, будущая и свежая метки, отсутствие заявки при
  удержании, сохранение хронологии и восстановление после
  отпускания и нового нажатия.
- Контроллер и CAN-мост собраны для M32R. Сквозная проверка
  `check_h03_link.py` прошла 18 компонентных групп и сравнила
  11 полей сквозной эмуляции с сохранённой трассой Bosch.
  Отдельная проверка `check_h03_input_binding.py` прошла на ПК и
  M32R. Общие наборы M32R прошли шесть компонентных и 17 нативных
  групп.
- Модель размещения `prefix-candidate` прошла шесть проверок CPU.
  При 118 корнях и полезной нагрузке 82 824 байта в основном
  окне осталось 904 байта. Новых статических данных в RAM нет.
- При `-Os -ffunction-sections -fdata-sections` код
  `lfj8_range_control_step_with_buttons` вырос с 408 до 420 байт
  в объекте M32R. Полный профиль `padding-candidate --with-bindings`
  завершился `FAIL_BINDINGS` с семью неразрешёнными привязками.

Основные команды воспроизведения с локальными путями:

```powershell
python -B -m model.run_integrated --cc $zig
python -B targets/lfj8/check_h03_link.py --base $h03 --gcc $m32rGcc --bridge local/audit/bridge/lfj8_9e1c_m32r.o --controller local/audit/controller/rbm_u340e_m32r_be.o --bosch-trace verification/project-audit/memory-layout/roundtrip.json --out local/audit/h03-link.json
```

## Открытые условия

Карта физического входа, допустимые интервалы, штатный вызов
из H03 и поведение автомобиля при потере источника требуют
отдельного подтверждения. Проверки этой порции выполнены
программно. Оборудование и запись блока не использовались.
Снимок общего аудита отмечает три изменённых файла для
обновления по результатам интеграции.
