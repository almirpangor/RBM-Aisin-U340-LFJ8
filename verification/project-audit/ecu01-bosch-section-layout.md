# ECU-01 — проверка размещения секций Bosch E4M3

Сборщик проверяет физические диапазоны всех секций перед записью в образ. Диапазон должен быть непустым, непрерывным и полностью входить в S04. Запрещены общие байты у секций и пересечения со штатным кодом момента или любой из 51 записи целостности. Соседние секции разрешены. Значения контрольных сумм по-прежнему пересчитываются после размещения. [Сборщик](../../targets/bosch/build.py)

## Регрессия

Вызов `build(..., with_engine_signals_tx=True)` с тестовой подстановкой `SPEED_ORIGIN=0x66800` и `SPEED_LIMIT=0x67000` воспроизводит совпадение диапазонов приёмника скорости и передатчика. В опубликованном `5e3ac74` передатчик перезаписал часть приёмника, а сборщик принял результат с 51 исправной записью целостности. Новый сборщик отклоняет размещение по файловому адресу `0x56800` до записи секций. Сценарий выполнялся в памяти.

С исходным S04 проверены все 12 допустимых сочетаний параметров сборщика. Получено восемь различных образов, по два варианта переходов для каждого профиля. Профили включают скорость, телеметрию, поля модели и обычный режим с полем 3. Образы, данные манифестов и листингов совпали с результатами `5e3ac74`. Во всех профилях сошлась 51 запись целостности. [Тесты диапазонов и записей](../../tests/test_bosch_build_integrity.py)

Компактный профиль ordinary имеет SHA-256 `bd0afefa40dfd1ea82e647ea5af7e64e2f652c27ccc5c3b91a986224fd77ec79`. В модели ST10 прошли 56 проверок допуска режима, 65 536 сравнений кодирования, 64 проверки допуска передачи, 6 смен входных данных и 3 задержки IF1. Результат `PASS_OFFLINE_ONLY` относится к этому профилю без cruise и override. Окончательный профиль и выпуск зависят от CAN-05, ECU-02 и REL-01. [Карточка ECU-01](../../docs/project-map.md#ecu-01)

На ПК с Zig 0.13.0 прошли все 37 шагов и 117 тестов Python. В сквозном сценарии тот же образ Bosch принял скорость из кадра `01ff0000ffff05a0` и опубликовал 1824 в Q7.

```powershell
python -B -m unittest discover -s tests -p test_bosch_build_integrity.py -v
python -B targets/bosch/build.py --engine $r4Engine --s04 $s04 --outdir $boschOut --with-model-fields --with-ordinary-model-field --compact
$image = Join-Path $boschOut 'E4M3_CHERY_ORDINARY_MODEL_NO_CRUISE_COMPACT_OFFLINE_ONLY.bin'
python -B targets/bosch/verify_ordinary_model_field.py --engine $r4Engine --s04 $s04 --model $c167Model --image $image --compact
python -B tools/build_pc_checks.py --cc $zig --out $pcOut --bosch-engine $r4Engine --bosch-s04 $s04 --bosch-image $image
```
