# TOY-05 — исходный снимок адаптаций Toyota S01

База опубликованного изменения `760628bd249b19051339403f5663e78187d12a9a`.
Прогоны выполнены на том же коде из `f36613136fffce586a2736c1ea043794784c5c6f`.
Следующий коммит базы меняет только список остатков в общем аудите.
Образ S01 `4770806_89663-52F01.bin` проверен по 753 664 байтам
и SHA-256 `a3cd723e7e21bf547ca4c17ec49a1e098d203773547dba4d7af21991a2cbead1`.

## Откуда берутся значения

При холодном пути `0540B0 → 0545E0` таблица из 96 дескрипторов по
`00ACA0` связывает все 34 байта `FactoryAdaptation` с байтовой
обёрткой группы 7. Для холодного восстановления обёртка берёт значения
из таблицы ROM `00B0E0`. Ниже указаны значения после разыменования
указателей. [Верификация пути восстановления в R3](https://github.com/almirpangor/Chery-TA2005-U340E/blob/7585de6945b4b6b3ef381c6062070a5f417cf588/research/results/TOYOTA_EVENT_RESTORE_VERIFICATION.json)

| Поле | GP | Число байтов | Адрес значения ROM | Значение каждого байта |
| --- | --- | ---: | --- | --- |
| Признаки обучения | `−4619…−4618` | 2 | `00B077` | `00` |
| Счётчики повышения | `−4600…−4595` | 6 | `00B07B` | `00` |
| Счётчики понижения | `−4594…−4593` | 2 | `00B07C` | `00` |
| Поправки повышения | `−4579…−4562` | 18 | `00B07D` | `00` |
| Поправки понижения | `−4554…−4550` | 5 | `00B07F` | `00` |
| Признак наблюдения понижения | `−4603` | 1 | `00B079` | `00` |

Снимок относится только к перечисленным полям. Например, соседние
`GP−4616…−4605` относятся к другому полю восстановления и на холодном
пути получают `80`. При исправном зеркале и режиме 0 или 1 донор
загружает сохранённые значения. Сам вызов `0545E0` при исправном
зеркале сохраняет обучение. [Перенос восстановления R3](https://github.com/almirpangor/Chery-TA2005-U340E/blob/7585de6945b4b6b3ef381c6062070a5f417cf588/toyota_isolation/event_restore.c)

## Контракт контроллера

`rbm_u340e_s01_adaptation_baseline` возвращает неизменяемый снимок.
Владелец запуска может передать его в
`rbm_u340e_runtime_restore_adaptation` при выборе S01. Пустые или
недостоверные слоты приводят к этому снимку. Исправная запись
восстанавливает сохранённые коррекции. Тот же снимок может использоваться
в явно запрошенной транзакции сброса после подключения носителя.
Цикл запуска H03 и операции NVM ещё предстоит связать.

## Проверки

- **S01 и ПК.** Скрипт сопоставил 34 дескриптора и байта ROM с
  фактическим снимком из собранной библиотеки контроллера. В отдельно
  собранном фиксированном переносе R3 прошли 240 случаев холодного
  fallback и 48 случаев сохранения обучения при исправном зеркале.
  Проверены три точки входа, грязные GP, два исходных состояния
  прерываний и режимы 0–3.
- **Унаследованная проверка V850.** Закреплённый отчёт R3 содержит 256
  сравнений полного корня `0540B0` с оригиналом, включая компактные
  смещения 443–476 для указанных полей. Контрольные суммы исходника и
  карты совпали после учёта LF/CRLF. Эти сравнения взяты из отчёта
  донора. [Сравнение холодного запуска R3](https://github.com/almirpangor/Chery-TA2005-U340E/blob/7585de6945b4b6b3ef381c6062070a5f417cf588/research/results/C167_TOYOTA_COLD_INIT_PROBE.json)
- **Сборка и модель M32R.** Новый сценарий прошёл для пустых слотов,
  исправной записи и отказа чтения. Проверено сохранение `GP−7184`.
  Повторены регрессии адаптаций и все 18 компонентных групп адресной
  модели H03 с сохранённой двусторонней трассой Bosch из свежей базы.
- **Общий прогон.** На ПК прошли 37 шагов и 113 тестов Python без
  пропусков. На M32R прошли 17 групп штатных путей и шесть
  дополнительных компонентных групп. Для запусков с абсолютными
  путями исходников использована отдельная рабочая копия с ASCII-путём.
- **Размещение кода.** В прогоне `check_h03_image_layout.py`
  к `EXTRA_ROOTS` добавлена `rbm_u340e_s01_adaptation_baseline`, выбран
  `prefix-candidate` и включён `--cpu-test`. Размещены 119 корней,
  82 858 байт Flash без дополнительной статической RAM. В основном окне
  осталось 868 байт, хвост занят полностью. Шесть сценариев исполнения
  по рассчитанным адресам прошли. Снимок вызван в тесте контроллера.
  Модель размещения ещё не включает все платформенные привязки.

```powershell
python -B targets/lfj8/check_toyota_adaptation_baseline.py --r1 $r1 --r3 $r3 --cc $zig --controller-lib local/pc-final/controller/rbm_u340e.dll --out local/final/s01-baseline.json
```
