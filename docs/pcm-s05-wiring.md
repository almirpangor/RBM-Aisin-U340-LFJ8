# Mazda LFJ8-18-881F и цепи PCM образа S05

Выбранная программная основа — `RB-J-P01.bin` (S05, 1 МиБ), внутренний номер `LFJ8-18-881F`, ПО `LFJ8EF030LFXF0A0`. Японский EPC Mazda относит этот номер к моторному PCM для Atenza 2.0 AT без иммобилайзера, с 1 февраля 2006 года, в том числе GGEP с номера кузова 401384. Каталожная группа `18-881A`. [Идентификация S05](mazda-pcm-s05.md), [японский EPC Mazda, позиция 18-881A](https://partsfan.com/mazda/jp/cfa8e992c101b77faa66502a1bfd973c/Y1/6600A/2G51721/18881A/)

Ниже приведены обозначения контактов из заводских источников для экспортной Mazda6 GG/GY с двигателем LF. Таблица служит для сопоставления с целевым экземпляром. Японская электрическая схема, подтверждающая эти обозначения для физического `LFJ8-18-881F`, пока отсутствует.

## Разъёмы и питание

В книге Mazda 5661-1E-05G двигатель LF входит в раздел `0140-1`. PCM обозначен `0140-101`. На рисунке `D6E140AW30122` показан разъём жгута. Номер контакта следует читать в направлении стрелки этого рисунка. Для японских DBA-GGEP 20F/20C/20E руководство установщика Clarion показывает четыре разъёма 30P / 27P / 30P / 30P с иной формой. Этот рисунок не даёт соответствия экспортным номерам контактов или привязки к конкретному аппаратному номеру PCM. Японское сервисное руководство для Atenza GG/GY с мая 2005 года зарегистрировано в FAINES. [Заводской рисунок D6E140AW30122](https://mazdamanuals.com/Mazda/md6%200605%201107/D923-1A-22C_Ver25/esicont/srvc/html/images/D6E140AW30122.png), [Clarion MA-68, стр. 2 и 4](https://www.clarion.com/jp/ja/files/speed/mazda/mazda_68C.pdf), [каталог FAINES](https://faines.jaspa.or.jp/enduser/registration_manual_list/120?page=1)

На фото соседней аппаратной ревизии `LFJ8-18-881E`, Mitsubishi `E6T54477H3`, видны два разъёма по четыре ряда, что согласуется с геометрией экспортного рисунка. Перенос нумерации и назначения полостей на конкретный блок `881F` требует сверки. [Фото этикетки](https://1cycytkm.p.crcdn.pro/drom/1649158079860_bulletin), [фото колодок того же экземпляра](https://1cycytkm.p.crcdn.pro/drom/1649158077195_bulletin)

| `1AM` / `1AI` | CAN-H / CAN-L | Красный / синий по листу `0140-1i`. PCM, отдельный TCM, ABS/DSC, приборная панель и диагностика включены в сеть Mazda |

## Входы для исследования на S05

| Контакт PCM | Штатная функция | Применимость к проекту |
| --- | --- | --- |
| `1AB`, `1AF` | Brake1 и Brake2 | В таблице Mazda при нажатой педали B+. Для функции тормоза U340E подтвердить электрическую цепь и логику двух линий исполнения |
| `2M` / `2N` | VSS− / VSS+ | Примечание 7 заводской таблицы ограничивает применение МКПП без ABS/DSC. Для 5AT штатный VSS идёт на `2P` отдельного TCM по листу `0517-1a`. У PCM S05 прямой вход VSS AT требует аппаратного подтверждения |
| `2W` и `2AQ` | Сигнал и питание CKP | `2AQ` имеет B+ при включённом зажигании. `2W` — кандидат для исследования входного тракта импульсов PCM при известном типе, амплитуде и частоте сигнала |
| `2S` и `2AM` | Сигнал и питание CMP | `2AM` имеет B+ при включённом зажигании. `2S` — второй кандидат для исследования входного тракта импульсов |
| `2AH`, `2AY` | Вход температуры ECT и общая масса ECT/MAP | Аналоговый кандидат для ATF U340E. Требуют проверки подтяжка, АЦП, характеристика датчика и реакция на обрыв/замыкание |
| `2AU` | Опорные 5 В для MAP | Для сравнения трактов и проверки схемы |

Clarion на японской конфигурации показывает зелёный сигнал скорости для навигации в нижней правой полости второго 27P-разъёма и отдельную точку подключения в промежуточном разъёме. Из этого источника известна точка съёма сигнала. Направление, уровни, полярность, пригодность в качестве входа VSS и привязка к выводам `2M/2N` остаются открытыми. Для P/R/N/D/L, Tiptronic и Overdrive контакты S05 под эти функции ещё не назначены. [Mazda D923-1A-22C, таблица напряжений](https://mazdamanuals.com/Mazda/md6%200605%201107/D923-1A-22C_Ver25/esicont/srvc/html/id0140a5802500.html), [Mazda 5661-1E-05G, 0140-1c/e/g и 0517-1a/c](https://manuale.clubmazda.ro/6mps/mazda_6_2006_wiring_workshop_manual.pdf), [Clarion MA-68](https://www.clarion.com/jp/ja/files/speed/mazda/mazda_68C.pdf)

Для японских GGEP/GGES с LF-VE от июня 2005 года справочник PIVOT указывает два разъёма по 60 мест и рисунок MA-6Ba. Четыре разъёма 30P / 27P / 30P / 30P по PIVOT относятся к более раннему LF-DE. Это уточняет применимость рисунка Clarion с четырьмя колодками. Полную электрическую распиновку позднего японского PCM показывает заводская схема конкретного исполнения. [PIVOT, таблица применяемости](https://pivotjp.com/download/pdf/wiring/e-nenpi-signal.pdf#page=8) · [Рисунок MA-6Ba](https://pivotjp.com/download/pdf/wiring/e-nenpi-signal.pdf#page=9)

## Штатные низкосторонние моторные выходы

Полярность ниже относится к конкретным нагрузкам моторного PCM. Отдельный Mazda TCM FS5A-EL на заводской схеме 2WD коммутирует плюс на соленоиды A–F и соленоид давления B. [Схема TCM и назначение контактов](lfj8-wiring-sources.md)

| Контакт | Нагрузка и режим Mazda | Место в исследовании U340E |
| --- | --- | --- |
| `2E` | Клапан фаз OCV, PWM. Катушка 6,9–7,9 Ом при 20 °C, питание от главного реле. По листу `0140-1d` цепь к PCM коричневая/жёлтая | Кандидат для проверки силового ключа PWM. Нужны ограничения тока, частоты, рассеиваемой мощности, цепь сброса энергии и доступность обратной связи |
| `2C` | Клапан продувки адсорбера, PWM, питание от главного реле. Контакт `2C` подтверждён таблицей PCM, диагностикой P0443 и листом `0140-1c`. Отдельная процедура проверки клапана в той же редакции указывает `4U` | Кандидат PWM. Расхождение номера и допустимый ток следует разрешить на целевом блоке до использования |
| `2I` / `2J` | Вакуумные клапаны впускного коллектора tumble / variable intake air. Катушки питаются от главного реле, штатное управление двухпозиционное | Кандидаты для проверки дискретных команд. Ток катушки, защита и пригодность к продолжительной модуляции не указаны |
| `2BB`, `2BC`, `2BD`, `2AZ` | Моторные форсунки № 1–4. Сопротивление одной форсунки 11,4–12,6 Ом при 20 °C. Питание через главное реле, штатные краткие импульсы впрыска | Кандидаты для исследования дискретных ключей, только после проверки ограничений по непрерывному току и теплу |
| `2BE`, `2BG` | Управление нагревателями HO2S и A/F. Заводская таблица содержит осциллограммы | Кандидаты для проверки PWM. Штатная нагрузка в основном резистивная. Пригодность защиты и ключей для соленоидов U340E не установлена |
| `1G`, `1I` | Управление ветвью бензонасоса и катушкой реле кондиционера соответственно. В графическом варианте без иммобилайзера это элементы № 16 и № 15 | Два штатных дискретных выхода для исследования независимого управления реле при дальнейшем перепрофилировании. Контакт `1I` содержит букву I |

Параметры Toyota в таблице относятся к указанным версиям коробки. Номера выводов Mazda из семейства `LFJ8-18-9E1x` относятся к отдельному TCM FS5A-EL с собственными разъёмами и силовыми драйверами коробки.
