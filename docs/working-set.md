# Комплект разработки Aisin U340E

Основа для АКПП — выбранный владельцем `RB-J-P01.bin` (S05, Mazda `LFJ8-18-881F`, SuperH big-endian). Основа для двигателя — Bosch ME7.9.71 GW4G15 E4M3 (S04). Для этой версии проведены программные проверки. Стенд из АКПП, Bosch и панели в работе не участвовал. [Выбор платформы](lfj8-target-identity.md) · [Исходное ТЗ](RBM_TZ_Aisin_U340_LFJ8_Codex_v1_0.pdf)

## Состав и запуск

- В ZIP файл `MANIFEST.json` содержит SHA-256 исходников, сборок и отчётов. Результаты команд ПК находятся в `reports/PC-CHECKS.json`.
- В каталоге `pc/` исполняемые файлы для Windows x64 проверяют управление U340E, чтение и очистку DTC, расчёт и сохранение поправки импульсного выхода. Из корня распакованного архива выполните в PowerShell:

  ```powershell
  & .\pc\u340e_controller_test.exe
  & .\pc\chery_dtc_test.exe
  & .\pc\chery_dtc_can_test.exe
  & .\pc\panel_pulse_test.exe
  & .\pc\lfj8_host_check.exe
  ```

- В каталоге `candidates/bosch/` лежит `E4M3_CHERY_SPEED_OFFLINE_ONLY.bin`. Он добавляет приём скорости через `0x1AE` и передаёт её штатной функции Bosch. Файл выпущен для программной проверки. В нём нет генератора сигнала панели и полной интеграции запросов момента и диагностики Chery. [Проверка Bosch и сборка](bosch-integration.md)
- Объекты SuperH в `objects/` собраны для целевой архитектуры. ELF в `emulation/` проверяют отправку кадров Chery и ядро U340E на уровне инструкций SH. Для применения в S05 нужны интеграция со штатным запуском, выделение памяти и драйверы подтверждённых физических цепей. Выпуск цельного BIN для записи в блок АКПП открыт. [Машинная проверка S05](pcm-s05-integration.md) · [Машинная проверка контроллера](toyota-integration.md)

Из каталога `source/` проверки ПК можно повторить в Python 3.10+ с Zig 0.13 или совместимым компилятором C11:

```powershell
python -B tools/build_pc_checks.py --cc zig --out local/pc-checks
```

Для сквозной проверки с инструкциями ST10 добавьте аргументы `--bosch-engine`, `--bosch-s04` и `--bosch-image` по [инструкции сборки Bosch](bosch-integration.md). Сценарий проверяет, что кадр скорости от C-компонента со значением 14,40 км/ч принят инструкциями кандидата, а модуль панели рассчитал период по полученной скорости 14,25 км/ч и номиналу 6000 имп./км.

## Подключение, запись и восстановление

[Карта цепей PCM](pcm-s05-wiring.md) содержит заводские данные с указанием применяемости к S05. Перечисленные в ней моторные выходы PCM коммутируют нагрузку на массу. Соленоиды U340E S1, S2 и ST требуют подачи плюса. Отдельный штатный TCM Mazda FS5A-EL подаёт плюс на свои соленоиды A–F. На выбранной плате и жгуте U340E требуется подтвердить полярность, назначение и ток каждого используемого канала. [Схема подключения TCM Mazda](lfj8-wiring-sources.md) · [Процедура подключения, проверки и восстановления](verification.md)

В актуальном коде контроллера добавлен декодер шести положений аналогового селектора. Для 2 и L рассчитаны номиналы 200 и 91 Ом. [Карта, измерения и программные пороги](lfj8-selector.md)

Перед записью требуется привязать профиль программатора и резервную копию к конкретному блоку с подтверждёнными аппаратными и программными номерами. Для S05 дальше нужны завершённая компоновка исполняемого приложения и исполнительные цепи АКПП. Для Bosch требуется подтверждение фактически установленного S04 и электрическая приёмка. Запись и восстановление с этим комплектом на аппаратуре ещё не выполнялись.
