# Идентификация S05 и донорских образов LFJ8

Для переделки владелец выбрал `RB-J-P01.bin`. В исходном ТЗ указан другой аппаратный номер `LFJ8-18-9E1D`. Каталог Mazda для японского Atenza 2.0 AT связывает `9E1D` с выпуском с июля 2006 года. Ранее применялись другие исполнения той же каталожной позиции. Переход каталожного номера запчасти подтверждает применяемость узла в соответствующих автомобилях. Возможность записи конкретного образа устанавливается отдельно. [Журнал решений](decisions.md) · [Mazda EPC, позиция 18-9E0](https://partsfan.com/mazda/jp/cfa8e992c101b77faa66502a1bfd973c/Y1/6600A/2G51721/189E0/)

| Образ | Внутренний идентификатор | Основание и применимость |
| --- | --- | --- |
| `RB-J-P01.bin`, S05, 1 МиБ | `LFJ8-18-881F`, ПО `LFJ8EF030LFXF0A0` | Моторный PCM Mazda, SuperH big-endian. Выбран владельцем для разработки. [Идентификация PCM](mazda-pcm-s05.md) |
| `LFJ8TB000LFXA0A0-20260806-160523(TCM-adapt).bin`, S06, 512 КиБ | `LFJ8-18-9E1B`, ПО `LFJ8TB000LFXA0A0` | Согласованный донор TCM на M32R. Его адреса описаны в донорском отчёте. [Анализ донора](lfj8-9e1b-vss.md) |
| `LFJ8-T-D.bin`, 512 КиБ, две совпадающие копии в архиве | `LFJ8-18-9E1C` по `0x031033`, ПО `LFJ8TC000LFXA0A0` | SHA-256 `844a11b809cda1f2ccaf90cb6a75666009487ccedd2e8190b7eb46137b855544`. От архивного образа с явным именем C отличается 13 байтами в диапазоне `0x210–0x22D`. Программная часть этих двух файлов совпадает. Владелец указал, что чтение могло быть выполнено с другого блока. |

В Windows видны USB-ключ Guardant Code и COM8 SMS-Software. Установлены драйверы Scanmatik SM2 и SM3. Сеанс с целевым LFJ8, измерения на нагрузке и целевой комплект подключения на момент проверки не идентифицированы. Для записи и подтверждения восстановления требуется установленное соответствие целевого ECU и исходного образа.
