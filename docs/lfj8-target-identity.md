# Целевой TCM 9E1D и проверенные образы LFJ8

Для аппаратной сборки владелец подтвердил отдельный TCM `LFJ8-18-9E1D` из ТЗ. Каталог Mazda для японского Atenza 2.0 AT связывает `9E1D` с выпуском с июля 2006 года. Переход каталожного номера запчасти подтверждает применяемость узла в соответствующих автомобилях. Возможность записи конкретного образа устанавливается отдельно. [Журнал решений](decisions.md) · [Mazda EPC, позиция 18-9E0](https://partsfan.com/mazda/jp/cfa8e992c101b77faa66502a1bfd973c/Y1/6600A/2G51721/189E0/)

| Образ | Внутренний идентификатор | Основание и применимость |
| --- | --- | --- |
| Родной образ целевого TCM | Требуется `LFJ8-18-9E1D` | Идентифицированного чтения с целевого 9E1D пока нет. |
| `RB-J-P01.bin`, S05, 1 МиБ | `LFJ8-18-881F`, ПО `LFJ8EF030LFXF0A0` | Моторный PCM Mazda, SuperH big-endian. Исследован при выборе платформы. [Идентификация PCM](mazda-pcm-s05.md) |
| `LFJ8TB000LFXA0A0-20260806-160523(TCM-adapt).bin`, S06, 512 КиБ | `LFJ8-18-9E1B`, ПО `LFJ8TB000LFXA0A0` | Согласованный донор TCM на M32R. Его адреса описаны в донорском отчёте. [Анализ донора](lfj8-9e1b-vss.md) |
| `LFJ8-T-B.bin`, H02, 512 КиБ | `LFJ8-18-9E1B`, ПО `LFJ8TB000LFXA0A0` | Заводская версия из рабочего архива. По ней проверены окна селектора и штатный CAN. [Реестр](../data/sources.json) |
| `LFJ8-T-D.bin`, 512 КиБ, две совпадающие копии в архиве | `LFJ8-18-9E1C` по `0x031033`, ПО `LFJ8TC000LFXA0A0` | SHA-256 `844a11b809cda1f2ccaf90cb6a75666009487ccedd2e8190b7eb46137b855544`. От архивного образа с явным именем C отличается 13 байтами в диапазоне `0x210–0x22D`. Программная часть этих двух файлов совпадает. Владелец указал, что чтение могло быть выполнено с другого блока. |

Скрипт [inspect_lfj8_tcm.py](../tools/inspect_lfj8_tcm.py) печатает SHA-256, длину и номер из метаданных по `0x031033`. На рабочем архиве он различает 9E1B и 9E1C и отклоняет оба при проверке ожидаемого 9E1D. Поддержан формат полного 512-КиБ образа, проверенный на архиве. Для дальнейшей привязки потребуются способ и охват оригинального чтения 9E1D, совпадение маркировки и возможность восстановления. [Проверка и приёмка](verification.md)

В актуальной проверке доступные архивы RB Motors содержат 9E1B и 9E1C. Диск G: отсутствовал, а Z: был отключён. В списке PCMflash есть профиль модуля 08 для Melco TCM Mazda5/6 512 КБ. Его применимость к конкретному экземпляру подтверждается успешной идентификацией и чтением. Результат проверки метаданных зависит от размещения строк в данной версии ПО. При другом размещении используют журнал чтения и разбирают образ отдельно. [Список протоколов PCMflash](https://forum.pcmflash.ru/forum/viewtopic.php?t=15670)
