# Калибровки донора LFJ8-18-9E1B

Владелец согласовал донор `LFJ8TB000LFXA0A0-20260806-160523(TCM-adapt).bin` для разработки. Размер 524 288 Б, SHA-256 `624790698dcb39000c2a070c07e14f4857e3a46cc32142c3ee5ac4689fd8b7cc`. Поля с `0x031033` образуют `LFJ8-18-9E1B`, по `0x031041` находится `LFJ8TB000LFXA0A0`. Проверены одинаковые копии в `G:\TCM` и в каталоге актуальных прошивок проекта на `Z:`. Применимость к целевому LFJ8-18-9E1D требует сравнения родного образа или проверенной идентификации ПО и аппаратной ревизии.

## Таблицы выбора передач

Повторно сверены 39 девятиточечных таблиц из прежнего анализа, всего 351 пара «аргумент–порог». В каждой таблице сначала идут девять значений аргумента, затем девять значений результата. Оба массива представляют 32-битные IEEE 754 числа в big-endian. Для всех таблиц проверены два загрузочных адреса, число узлов и путь к одной функции интерполяции `0x095B4`. В 30 местах присутствует прямой вызов. Девять остальных путей переходят в общие блоки по `0x4B774` или `0x4AC7C` и далее в ту же функцию.

Прежнее исследование трактует аргумент как расчётную нагрузку в процентах, а результат — как порог скорости автомобиля в км/ч. Документация Mazda подтверждает существование диагностических величин `THOP` и `VSS` в этих единицах. Для окончательной привязки требуются трассы источника аргумента, сравниваемой скорости и итоговой команды передачи. Имена ветвей и указанные единицы зафиксированы здесь со статусом интерпретации. [Mazda D923-1A-22C, PID/Data Monitor FS5A-EL](https://mazdamanuals.com/Mazda/md6%200605%201107/D923-1A-22C_Ver25/esicont/srvc/html/id050221805600.html)

## Таблицы регулирования

Проверены 12 сеток по 6 строк и 9 столбцов, всего 648 ячеек. Строки расположены последовательно, значения имеют тот же формат float32 BE. Функция `0x36FB0` подаёт в интерполяцию узлы столбцов `0x18000` и массив индексов `0x18024` (0…8), узлы строк `0x18BD0` и массив индексов `0x18BE8` (0…5). Вызовы осевых интерполяций видны по `0x3702C` и `0x37040`. Вызовы `0x096D4` используют полученные координаты для расчёта по сетке, в том числе по `0x3718C`. Ось столбцов имеет узлы `0 / 12,5 / 25 / 37,5 / 50 / 62,5 / 75 / 87,5 / 99,60938`, ось строк — `−20 / 0 / 20 / 40 / 80 / 120`.

Код загружает по две сетки для расчёта. В ветвлении `0x37008–0x37068` участвуют значение из RAM `0x804F24` и опоры `600` (`0x198D8`) и `1000` (`0x198D4`). Нижняя и верхняя ветви используют отдельные сетки. В промежуточной ветви видны два вызова расчёта по сетке и вычисления с обеими опорами. Значения пары ниже указаны в порядке от нижней опоры к верхней.

| --- | --- | --- |

В прежнем анализе ось строк связана с температурой ATF, ось столбцов — с запросом в процентах от опорного давления. Результат интерпретирован как составляющая команды ШИМ с последующей коррекцией. Для первой пары по порядку программных каналов предложен SSC. Для коробки FS5A-EL руководство Mazda указывает SSC как отдельный канал ШИМ на контакте `1C`, температуру ATF на `2M`, а расчётное давление и ток клапана как отдельные диагностические величины. Для переноса необходимо прозвонить выход конкретной платы, подтвердить потребляемый ток, полярность, частоту, зависимость давления и границы переходных процессов с измерениями. Toyota U340E потребует отдельного сопоставления для S1/S2, ST, SLT и SLU. [Mazda D923-1A-22C, PID/Data Monitor FS5A-EL](https://mazdamanuals.com/Mazda/md6%200605%201107/D923-1A-22C_Ver25/esicont/srvc/html/id050221805600.html)

## Воспроизведение и применимость

[Скрипт сверки и извлечения](../tools/inspect_9e1b_calibration.py) работает через стандартную библиотеку Python. По умолчанию выводит SHA-256 и число таблиц, с `--json` печатает смещения, числовые массивы и ссылки из кода. Инструкция `LD24` и вычисление адресов `BL`/`BRA` проверены по руководству M32R. [Renesas M32R Family Software Manual, §§ 2.1.4, 3.2](https://www.renesas.com/en/document/mas/m32r-family-software-manual)

```powershell
python tools/inspect_9e1b_calibration.py '<путь к согласованному LFJ8TB000…(TCM-adapt).bin>' --json
```

Локально подтверждены 39 таблиц, 351 узел, 12 сеток и 648 значений. JSON разобран повторно, обе опоры совпали с `600/1000`. В контрольном запуске входной файл `RB-J-P01.bin` отклонён по размеру и SHA-256. Прежний `maps.mjs` из `rbm-lfj8-lfs3-calibration-01a1d387` содержит SHA-256 обоих анализировавшихся образов. Все 702 значения одномерных таблиц, 648 ячеек и 15 узлов осей 9E1B сверены с `maps.json` этого исследования с учётом его округления до девяти значащих цифр. Сравнение с `LFS3-T-A.bin` выявило 116 отличающихся узлов и 638 изменённых ячеек. Этот второй образ использован для проверки происхождения отчёта. В экспорт входят только данные согласованного 9E1B.

Для сопоставления с Toyota используйте [отчёт по Toyota U340E](toyota-u340e.md) и экспорт 9E1B по последовательностям `положение селектора → выбранная ветвь → вход расчёта нагрузки и скорости → порог → решение`. Контуры давления сопоставляются по назначению и измеренной реакции клапана. Смещения, числовые значения карт и коэффициенты Mazda относятся к коробке, для которой создан донор. Испытания с U340E ожидают подтверждённых калибровок Toyota и карты выходов целевого блока.
