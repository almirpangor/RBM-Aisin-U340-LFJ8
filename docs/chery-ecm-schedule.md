# Расписание CAN Chery ECM по исходному S02

Проверен образ `CHERY_REFERENCE_DO_NOT_FLASH.bin` с SHA-256 `99dc271a861ab6d9e6749e8beb4637ab5c6c7e111f3ff0d9df4e147b2a0a6e1c`. Адреса — смещения в образе. Поля и цепи обработки документированы в [разборе ECM](chery-ecm-static.md).

## Планировщик

1. По `018BDA–018BF8` код задаёт `T4CON=0x0006`, затем включает таймер битом 6. Регистры `FF44` и `FE44` соответствуют `T4CON` и `T4` GPT1. Для `T4I=6` делитель равен 512. [STMicroelectronics, ST10F276E, таблица 46 и список SFR](https://www.st.com/resource/en/datasheet/st10f276e.pdf)
2. По `094232–094246` регистрация через `0192EE` задаёт callback `094038` с периодом `0x030D` (781 отсчёт) и начальным сроком, установленным по снимку таймера с добавкой `0xEA`. Код `094126–094164` обновляет период канала 1 через `01970E`. Текущие константы ROM `B9DF8=4`, `B9DFA=250` и байтовый `F7C2` дают `781 + 4 × max(F7C2 − 250, 0)`, то есть 781–801 отсчёт.
3. `094038` берёт указатель `8816` и вызывает постановку в очередь `01883C`. Варианты `094B88` и `094BD2` выбирают дескрипторы `BA272` и `BA282`. В обоих вызывается задача с обработчиком CAN `0A2A36`, по `0946CA` для `09454A` и по `09483A` для `0947DA`. Расчётное время регистрации задач определяется как `ticks × 512 / fCPU` секунд. При 40 МГц это **9,9968–10,2528 мс**. Логика допускает влияние очереди на фактическое исполнение.

| Кадр | Действие в `0A2A36` | Программный интервал |
| --- | --- | --- |
| `0x0FA` | При бите 5 маски `AA2A6` вызвать `0A1FCC`, затем `020530` для TX-объекта 12 | Заявка на каждом вызове, бит включён в S02 |
| `0x278` | При бите 1 той же маски вызвать `0A1CA2`, затем `020530` для TX-объекта 8 | Заявка на каждом вызове, бит включён в S02 |
| `0x1AE` | Программный RX-индекс 0. После опроса `8C77=1`. `B85AE=15` | Опрос через один вызов при сохранении входных разрешений. Признак пропуска на 16-м неуспешном опросе |
| `0x300` | Программный RX-индекс 1. После опроса `8C76=5`. `B85AF=5` | Опрос на каждом шестом вызове при сохранении разрешений. Признак пропуска на шестом неуспешном опросе |

В `AA2A6` лежит `00FF`, маска RX по `A818A` равна `FF`. Для `0x1AE` и `0x300` также проверяется текущее разрешение `FD02.13`. Периоды опроса описывают приёмник. Интервалы заявок TA2005 рассчитаны отдельно по [его таймеру и планировщику](chery-ta2005-static.md).

## Настройка битрейта CAN1

`0A29D8` вызывает `093A10` с `R12=1`. Ветка `093A46` записывает `0x6B03` в `CAN1BTR` (`EF06`), `093A84` обнуляет `CAN1BRPER` (`EF0C`). Это делитель 4, 20 Tq на бит и расчётный битрейт `fCAN / 80`. При такте CAN 40 МГц получается 500 кбит/с. Фактический `fCAN` зависит от генератора и настройки делителя данного аппаратного исполнения. [STMicroelectronics, ST10F276E, таблица X-регистров](https://www.st.com/resource/en/datasheet/st10f276e.pdf) · [UM0404, гл. 21](https://www.st.com/resource/en/user_manual/cd00153027.pdf)

Скрипт сверяет SHA-256, опорные команды, дескрипторы задач, маски и калибровки с исходными байтами.

```powershell
python tools/verify_chery_ecm_schedule.py 'C:/path/to/CHERY_REFERENCE_DO_NOT_FLASH.bin'
```
