# Mazda LFJ8-18-9E1D и цепи TCM FS5A-EL

Справка по поиску схемы для проекта U340E. Заводское руководство Mazda устанавливает функции контактов штатного TCM FS5A-EL. Точный номер `LFJ8-18-9E1D` удалось сопоставить с маркировкой и геометрией корпуса на опубликованных фото. Электрическая привязка распиновки к экземпляру RB Motors требует подтверждения перед подключением.

## Контакты штатной FS5A-EL по D923-1A-22C

Кандидаты для проверки на `LFJ8-18-9E1D`. Обозначения `1O` и `2O` содержат букву **O**. Направление сигнала указано относительно TCM.

| Контакт | Направление | Функция в системе Mazda |
| --- | --- | --- |
| `1K` | Питание | Постоянный B+ от аккумулятора |
| `1M`, `1N` | Питание | B+ от штатного главного реле после включения зажигания |
| `1O`, `1P` | Масса | Массы TCM, руководство использует их как опорные точки измерений |
| `2O` | Масса датчиков | Общая опора датчиков, в том числе температуры ATF и положения селектора |
| `2R` | Выход | Управление штатным главным реле. При включённом зажигании в таблице Mazda указано менее 1 В |
| `2W`, `2X` | Двунаправленная пара | Соответственно CAN_H и CAN_L |
| `2H` | Вход | Аналоговая кодировка положений селектора от TR switch. Ориентиры Mazda при включённом зажигании — P 4,6 В, R 3,9 В, N 3,2 В, D/M 2,5 В |
| `2B` | Вход | Отдельный переключатель M-range. Активный уровень по таблице Mazda менее 1 В |
| `2D`, `2F` | Входы | Повышение и понижение передачи. Активный уровень по таблице Mazda менее 1 В |
| `2I`, `2K` | Входы | Соответственно положительная и отрицательная линии датчика скорости входного вала / турбины |
| `2L` | Вход | Датчик вращения промежуточной ступени |
| `2P` | Вход | Штатный датчик скорости VSS |
| `2M` | Вход | Температура ATF. Ориентиры Mazda при включённом зажигании — 3,3 В при 20 °C, 2,4 В при 40 °C, 1,5 В при 60 °C |
| `2J` | Вход | Выключатель давления фрикциона переднего хода |
| `1L` | Выход по сервисной таблице | Импульсный сигнал скорости для BCM. В жгуте на листе `0517-1a` эта полость отмечена как свободная. Наличие провода зависит от исполнения |
| `1A`, `1B`, `1C` | Подача плюса, ШИМ | Соленоиды переключений A, B и C соответственно. Вторые выводы соединены с массой |
| `1F`, `1H`, `1J` | Подача плюса, вкл./выкл. | Соленоиды переключений D, E и F соответственно. Вторые выводы соединены с массой |
| `1E`, `1G` | Пара выхода | Соленоид регулирования давления A, линии `+` и `−` соответственно |
| `1D` | Подача плюса, ШИМ | Соленоид регулирования давления B. Второй вывод соединён с массой |
| `1I`, `2A`, `2C`, `2E`, `2G`, `2N`, `2Q`, `2S`, `2T`, `2U`, `2V` | Назначение отсутствует в таблице | Требуется установить, какие позиции имеют контакты и какие цепи реально разведены |

Данные взяты из таблицы напряжений на выводах и раздела проверки осциллографом. Схема разъёмов на странице задаёт вид `2×12` для группы 2 и `2×8` для группы 1. Диагностические уровни Mazda относятся к условиям, указанным в заводском руководстве. [Mazda D923-1A-22C, TCM Inspection [FS5A-EL]](https://mazdamanuals.com/Mazda/md6%200605%201107/D923-1A-22C_Ver25/esicont/srvc/html/id051721800300.html).

## Что требуется связать с проектом U340E

На листе `0517-1b` видно, что TCM подаёт плюс на соленоиды переключений A–F и соленоид давления B. Вторые выводы подключены к массе. Сервисное руководство Mazda подтверждает полярность проверкой самих соленоидов. Полярность выходов моторного PCM описана по конкретным цепям в справке S05. [Схема 0517-1b](https://manuale.clubmazda.ro/6/mazda_6_2006_wiring_workshop_manual.pdf#page=109) · [Первичный гидроблок](https://mazdamanuals.com/Mazda/md6%200605%201107/D923-1A-22C_Ver25/esicont/srvc/html/id051721807700.html) · [Вторичный гидроблок](https://mazdamanuals.com/Mazda/md6%200605%201107/D923-1A-22C_Ver25/esicont/srvc/html/id051721807900.html) · [Цепи PCM S05](pcm-s05-wiring.md)

- Для скорости сначала подтвердить вход VSS, электрический тип и измеряемый сигнал. Затем применить требование ТЗ `100/22` и предусмотренный путь LFJ8 → CAN Chery → Bosch → панель.
- Для режимов установить физическую возможность использовать каналы `2B`, `2D`, `2F` и отдельный вход Overdrive. Mazda описывает отдельное положение M и кнопки, а в таблице селектора есть P/R/N/D и отдельный M. Отдельный уровень `L` и вход Overdrive в этой схеме не указаны. Распознавание `L`, Overdrive и переключение Auto ↔ Tiptronic одним нажатием зависят от схемы целевого жгута и проектной логики.
- Для реле исследовать `1F`, `1H`, `1J` как подтверждённые в руководстве переключаемые выходы соленоидов D, E, F. Использование любого из них возможно после распределения выходов U340E и проверки полярности, тока катушки и цепи защиты с эквивалентом нагрузки. Сохранить `2R` как цепь управления главным реле при штатном включении. На листе `0517-c` цепь заднего хода относится к переключателю диапазонов и BCM. Для позиций с прочерком в руководстве сначала проверить контакт, дорожку и драйвер.
- Для соленоидов сопоставить исполнительные элементы U340E с реально доступными драйверами. Логика Mazda FS5A-EL, электрические параметры её соленоидов и распределение выходов относятся к штатной коробке Mazda.
- Для CAN подтвердить пару `2W/2X` на конкретном жгуте, физический трансивер, терминацию и скорость. Карту сигналов Chery проверить по своим донорам и записи обмена. Электросхема устанавливает физическую сеть Mazda и её участников, а статическая карта из `RB-J-P01.bin` относится к самому исследованному образу.
- Идентификацию способа чтения и применимой прошивки TCM вести по маркировке и идентификации сессии программатора. В `RB-J-P01.bin` обнаружено обозначение ПО из семейства `LFJ8-18-881*`, которое EPC относит к PCM. Для отдельного файла TCM требуется подтвердить связь с `LFJ8-18-9E1D`, тип чтения и состояние калибровок.
