# Общая сборка и память H03 — 21.11.2026

**Все 42 опубликованные порции и локальный CAN-01 84b4433 объединены. Рабочий TCM BIN не выпущен.** Цель — LFJ8-18-9E1C на H03 LFJ8-T-D.bin, U340E и Bosch ME7.9.71 E4M3. [Подробные проверки](../verification/project-audit/final-integration-20261121/README.md) · [Машинный аудит](../verification/project-audit/2026-11-21-final-integration.json) · [Карточки задач](project-map.md).

После этой интеграции добавлена подтверждённая холодная процедура Toyota: 258 сравнений всех 828 байт, проверки ПК/M32R и шесть групп размещённого ядра прошли. Она сохраняет 685 байт чужих для неё исходных данных и пока не завершает startup provider. [Новый результат](../verification/project-audit/toy05-s01-cold-state.md).

## Результат общей проверки

| Проверка | Результат |
| --- | --- |
| ПК | 41 этап, 172 теста без пропусков |
| M32R | 18 стандартных + 8 дополнительных групп |
| Штатные пути H03 | 22 группы, включая 62 сценария запуска и 80 IRQ-контекстов |

При объединении были найдены недостающие include диагностики в четырёх сборщиках/проверках. Они исправлены. Отдельно устранено неявное отключение нового CAN-адаптера в native binding. Простое отсутствие конфликтов Git не выявляло эти ошибки.

## Память

| Состав | Байт | Граница результата |
| --- | ---: | --- |
| Удерживаемое ядро | 84904 | Прежний prefix-кандидат не вмещает; padding-кандидат заново прошёл шесть групп CPU |
| Известный CAN/датчики/нижний BasicCAN/native binding | 101460 | С явным тестовым профилем, но без 10 поставщиков; не готовая программа |
| Кандидатные области, включая нижний RX | 110548 | Заполнение FF не доказывает владение; весь окончательный код ещё не учтён |

Часть сервисных и других ASM-переходов проверена отдельно. Их нельзя считать установленными в одном исполняемом файле по этому замеру. Удаление штатного кода без доказательства его ненужности не выполнялось.

## Точный отказ общей линковки

Определение rbm_h03_application_binding теперь существует. При его реальном включении раскрывается следующий список:

| Неопределённый символ | Что должно поступить | Направление |
| --- | --- | --- |
| rbm_h03_target_takeover_ops | Реальные операции арбитража, выдачи и снятия выходов | H03-05/H03-03 |
| rbm_h03_target_startup_gear, rbm_h03_target_startup_gp | Подтверждённое исходное состояние Toyota | TOY-02/03/05 |
| rbm_h03_target_engine | Общие CAN/RAM/DTC и источник контекста двигателя | CAN-01/TOY-02 |
| rbm_h03_target_ram_owned | Допуск владения памятью во всех режимах | H03-04/REL-02 |
| rbm_h03_target_clock_ready | Доказанный источник и непрерывность часов | H03-02/VSS-02 |
| rbm_h03_target_initialize | Единый запуск владельцев и источников | H03-03 |
| rbm_h03_target_take_toyota | Полный согласованный снимок и событие Toyota | H03-03/TOY-02/04 |
| rbm_h03_target_service_phase | Обслуживание CAN, диагностики, режимов и выдачи | H03-03/CAN-03/DTC-02 |
| rbm_h03_sensor_config | Параметры датчиков из подтверждённых данных | VSS-02 |

Кроме этих десяти ссылок, остаются целевой профиль, постоянная память/адаптации, шкалы нагрузки Toyota, SLT/SLU, установка всех переходов и аппаратные критерии. Для TIO9/P97 штатный общий запрет не доказал снятие PWM; новый допуск требует подтверждённой изоляции или отдельного проверенного пути SLU. Тестовые разрешения и числа не перенесены в рабочий профиль.

## Куда продолжать

Каждая прежняя карточка в [project-map.md](project-map.md) содержит сданный результат, оставшееся действие и файлы. H03-03 уже не должен заново писать оболочку binding — нужно реализовать перечисленных поставщиков по реальным источникам. H03-04 работает с полным составом, а не со старым размером 94770 байт. CAN-05 уже имеет машинный профиль T4/IF1; его остаток — окончательная RAM/квалификация/арбитраж.

Готовый TCM BIN можно объявить только после целевой компоновки, установки переходов, проверки целостности и соответствующих проверок запуска/выходов. Текущий ELF и Bosch OFFLINE_ONLY этим условиям не соответствуют. Порядок физических проверок — [минимальный протокол](lfj8-9e1c-minimum-bench.md).
