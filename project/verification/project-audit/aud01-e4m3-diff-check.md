# AUD-01. Офлайн-сверка диапазонов E4M3

База — `main` `ae393e852fd8e110892c6725f219f3e43585d33c`. Проверка использует [данные сравнения](../../data/e4m3-diff.json) и [реестр исходников](../../data/sources.json). Образы читаются из Git-объектов закреплённых коммитов R1 и R4. Скрипт сверяет путь, размер, SHA-256 и Git blob ID, сопоставляет E4M3 с S04, сравнивает байты в каждой группе копий и пересчитывает включительные границы каждого непрерывного диапазона.

```powershell
python -B -m tools.check_e4m3_diff --r1 $r1 --r4 $r4
```

Результат — `PASS_OFFLINE_ONLY`. Совпали восемь файлов, три группы копий и все 1057 диапазонов.

| Сравнение | Различающихся байт | Непрерывных диапазонов |
| --- | ---: | ---: |
| REV8 → E4M2 | 11 304 | 381 |
| REV8 → E4M3 | 11 322 | 381 |
| E4M2 → E4M3 | 1 765 | 295 |

Отрицательные проверки использовали копии данных в памяти. Скрипт отклонил однобайтный сдвиг диапазона при прежних суммах, неверный blob ID S02, несовпадающие байты в группе копий и расхождение между E4M3 и S04. Отдельно проверены изменения в первом и последнем байтах, отсутствие отличий и отказ для файлов разной длины.

Проверка относится к архивным данным на ПК. Общий снимок аудита остаётся в ведении интегратора. `project_status.py --check` помечает новый скрипт для проверки перед включением в этот снимок.
