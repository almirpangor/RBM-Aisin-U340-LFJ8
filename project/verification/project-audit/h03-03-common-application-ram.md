# H03-03 · RAM приложения и штатный сервис CAN в общем линке

Основание — `main f64eff7`, сданная подготовка сервиса `d7c758f` и общий вариант ранних IRQ/DMA4 `1ca2f19`. Проверен H03 с SHA-256 `844a11b809cda1f2ccaf90cb6a75666009487ccedd2e8190b7eb46137b855544`.

## Подключение

`tools/check_h03_image_layout.py --with-can-service` подключает четыре штатных модуля сервиса CAN и два ASM-модуля TX13. Режим использует уже связанные переходы BasicCAN и свежий типизированный отчёт RAM. Сервис подготовки, foreground и остановки удерживается в общем графе вместе с приложением. Переход с `0x00C34C` помещается по штатному адресу, а штатное продолжение связывается с `0x00C350`.

Новый режим разрешает ссылки через единственный инвентарь H03. В обычном расчёте закрылись пять исходных ссылок: состояние приложения, снимок датчиков, признак квалификации TML0, ATF и селектор ADC. Поле `rbm_h03_application` занимает существующие восемь байт `control/application` по `0x806EF8–0x806F00`. Профильный расчёт подтвердил все 13 алиасов, включая единственного CAN owner по `0x808F48`, сервис CAN и рабочие поля TX13. Компоновщик отклоняет второй выделенный объект и несовпадающий абсолютный адрес. Новых объектов RAM для этих алиасов нет.

## Общая проверка

- В сопоставимом составе BasicCAN/DMA4 число неопределённых символов снизилось с семи до двух. Остались `rbm_h03_application_binding` и `rbm_h03_sensor_config`. Удерживаемый Flash вырос с 97 680 до 100 084 байт, отдельно существующий указатель IRQ сохраняет четыре байта. Из прибавки четыре байта занимают замену штатного слова TX13.
- Общий линк сохраняет `FAIL_BINDINGS`. Компоновщик связал независимый TX13 по его адресам из того же плана и проверил слово `ff008443`, загрузку общего owner, вытеснённую инструкцию и возврат. В этом расчёте цель перехода — `0x02D458`.
- Профильная регрессия `check_h03_can_monitor_revoke.py` теперь вызывает этот публичный режим без временной подстановки списка модулей и ASM-алиасов. Реальный сервис и точки подготовки, foreground, остановки и отзыва TX13 удержаны. Объём профильного расчёта — 101 316 байт Flash. Проверочный заголовок входит только в этот прогон. Состав по-прежнему ждёт остальных поставщиков приложения и параметров реального профиля.
- На связанном раннем ELF повторены оба сброса и отказ DMA4 для слова указателя BasicCAN. Отдельно прошли 18 сценариев TX13 на штатных путях foreground и CAN0 IRQ, штатный сценарий сервиса CAN с отказами и 53 проверки семейства H03 на ПК.
- Прошли 22 группы `native`, 8 групп `components` и 6 групп исполнения размещённого ядра. Режим CAN без ранней DMA4-защиты также проверил связанное слово TX13 и вернул те же две неопределённые ссылки.
- Все 41 этап ПК прошли. Python сообщил 190 тестов, один пропущен из-за отсутствия локального образа S03.
