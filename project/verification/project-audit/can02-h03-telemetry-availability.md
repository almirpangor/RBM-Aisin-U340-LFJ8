# CAN-02 — телеметрия H03 при недоступной скорости S51

База `main f64eff7`, сданные CAN-03 `1eefa2a` и DTC-01 `0941e55`. Использован H03 LFJ8-18-9E1C с SHA-256 `844a11b809cda1f2ccaf90cb6a75666009487ccedd2e8190b7eb46137b855544`.

В штатной сервисной фазе H03 квалифицированные поля статуса теперь поступают к брокеру TX13 и при отсутствии калибровки скорости. Брокер передаёт их существующему кодировщику Chery. Для `0x1AE` отсутствие геометрии, отсутствие S51 или несовместимая частота дают предусмотренное кодировщиком `0xFFFF`. Для `0x300` используется ATF из того же снимка с проверкой возраста. При недоступности самих полей статуса или потере допуска отправка телеметрии закрыта.

В регрессии оба кадра были готовы одновременно с диагностическим запросом. TX13 сначала выдал диагностический ответ, затем `0x1AE` с `FFFF` и `0x300` с валидной температурой. Проверено продвижение счётчика `0x1AE` и отсутствие записи после потери допуска при повторном предъявлении прежнего поколения. В прежней версии брокера новый сценарий падал на первой ожидаемой отправке `0x1AE`.

- В M32R прошёл тест брокера, включая новую регрессию, и 22 группы нативной модели. Также прошли 8 групп компонентной модели.
- На ПК прошёл 41 шаг. Из 185 Python-тестов 184 прошли, один пропущен. Сквозная проверка с моделью Bosch вернула `PASS_OFFLINE_ONLY`.
- В отдельных вызовах `probe_binding` точного H03 для тестового профиля использованы `.vehicle = NULL` и `.tick_hz = 500000u` при свежем снимке S51 с одним импульсом за 26 400 тиков. Каждый вариант исполнил 16 шагов связанного пути и два отказа при отсутствующем перенаправлении. Проверены отправки `0x1AE/0x300`, диагностика и отзыв. Изменения профиля применены только в памяти Python-проверки. SHA-256 отчёта `abdc21fb632c6589dcfbdcab57ac37ff16b8f5f1a0d2624f9cb02292f12d8f15`.
- В M32R medium размер секций двух изменённых объектов сократился с 2 704 до 2 656 байт. Статическая RAM в этих объектах отсутствует. Окончательные расходы Flash и глубина стека относятся к общей сборке.

```powershell
python -B tools/check_integrated_h03.py --suite native --base $h03 --gcc $gcc --controller $controller --bridge $bridge --out $nativeDir --jobs 2
python -B tools/check_integrated_h03.py --suite components --base $h03 --gcc $gcc --controller $controller --bridge $bridge --out $componentsDir
python -B tools/build_pc_checks.py --cc $zig --out $pcDir --bosch-engine $engine --bosch-s04 $s04 --bosch-image $boschOffline
```

Общий компоновщик находится в резерве H03-03. Установка TX13 в общем ELF и измерения физических окон приёма `0x5E9` остаются открытыми. Нативная модель не подтверждает калибровку S51 и обмен на блоке.
