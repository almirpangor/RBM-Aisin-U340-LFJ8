# TOY-03 — источник штатного P/N в H03

Toyota S01 получает GP−5722.2 инверсией GP−5471.1 и сопоставляет этот бит с положением P/N. Для этой проверки сигнал H03 должен иметь собственный физический источник. Штатный флаг `0x806446` зависит от того же AN2, по которому проект определяет положение селектора. [Границы GP Toyota](../../docs/toyota-integration.md) · [Карта входов H03](../../docs/lfj8-h03-input-paths.md#независимые-признаки-диапазона-toyota-toy-03)

## Путь в штатном H03

Проверен `LFJ8-T-D.bin` с SHA-256 `844a11b809cda1f2ccaf90cb6a75666009487ccedd2e8190b7eb46137b855544`. Перед запуском сравнивается весь штатный участок ELF с исходным файлом.

| Адрес | Что делает штатный код |
| --- | --- |
| `0x040370` | Сохраняет результат ADC0 AN2 в `0x804BC6`. |
| `0x034D14` | Сдвигает три предыдущих напряжения по адресам `0x804F0C`, `0x804F10`, `0x804F14`. В `0x804F08` сохраняет `AN2 × 5/1024`. При значении 300 по адресу `ROM[0x0166A4]` сохраняет слово `ROM[0x016840]`. В исходном H03 профиль по этому адресу равен 0. |
| `0x039DAC` | Сопоставляет четыре значения напряжения с переданными границами окна. |
| `0x03AC28` | Использует окна P, R и N из ROM. Ветви `0x03AEF8`, `0x03AF28`, `0x03AF58` вызывают проверку окон и публикуют соответствующие признаки. Ветвь `0x03AF78–0x03AFA0` записывает P или N в `0x806446`, а `0x03AFE8–0x03AFEC` сохраняет маску диапазона в `0x80622C`. |

Сервисная таблица Mazda FS5A-EL указывает одну клемму TCM 2H для декодированного `TR` и измеренного `TR_SENS`. Номинальные окна Mazda P, R, N и D согласуются с границами ROM H03 с округлением до сотых вольта. [PID/Data Monitor Inspection Mazda](https://mazdamanuals.com/Mazda/md6%200605%201107/D923-1A-22C_Ver25/esicont/srvc/html/id050221805600.html)

## Проверка M32R

На GCC 4.8.0 прошли все 1024 кода AN2, включая проверку точных 32-битных значений напряжения во всех четырёх ячейках истории. Затем проверены 20 вызовов штатной классификации по последовательности D→P→N→R→D. В начале каждого блока записано одно значение AN2, которое повторно использовалось в следующих трёх вызовах без новой записи АЦП. Первые три вызова дали нулевую маску, а четвёртый подтвердил новый диапазон. Штатный P/N подтвердился в P и N, включая сброс на смешанной истории P→N. Это число вызовов модели. Период и задержка на блоке требуют измерения.

В отдельном сценарии профиль 300 и подстановка 3,25 В заданы только в памяти симулятора. Через четыре вызова при меняющихся кодах AN2 появилось N и установился P/N. Отдельно прошли пять сравнений штатного пути захвата ADC0 AN2 и пути с целевым перехватом. [Проверка окон](../../targets/lfj8/check_h03_range_pnp.py) · [Проверка захвата](../../targets/lfj8/check_h03_selector_adc.py)

```powershell
python -B targets/lfj8/check_h03_range_pnp.py --base $h03 --gcc $m32rGcc
python -B targets/lfj8/check_h03_selector_adc.py --base $h03 --gcc $m32rGcc
```

## Следующая проверка на жгуте

Приоритетный кандидат для GP−5722.2 — отдельный контакт разрешения пуска. Шаг 13 процедуры Mazda проверяет цепь от PCM 1B до реле стартера в P/N; шаг 18 отдельно проверяет `TR` через TCM 2H. Для целевого U340E/Bosch остаётся проследить контакт до доступного входа, записать одновременно его уровень и AN2, измерить полярность и задержку и проверить реакцию при несовпадении. До подтверждения применяется действующее требование пригодности независимого входа.
