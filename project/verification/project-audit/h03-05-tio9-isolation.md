# H03-05 — допуск изоляции TIO9/P97

Основа ветки — `main` `20bf48d` с форматом доски 2. Включены ранее сданные порции `f3bb500`, `4baf99c`, `57bf9ee` и `8e866f4`. Последняя сохраняет отзыв команды, полученный во время арбитрации. [Предыдущая порция H03-05](h03-05-latch-revoke.md)

## Изменение

После штатного общего запрета `0x8063F2` выход P31 выключается. TIO9/P97 продолжает формировать PWM в исходной функции выдачи. Прежняя четырёхбитная маска охватывала A/B/C/Pressure B. Тест на прежнем коде воспроизвёл допуск при `isolated_pwm_mask = 0x0F`. [Проверка штатных путей H03](toy06-h03-slu-output-paths.md)

В [интерфейсе H03](../../targets/lfj8/lfj8_h03_takeover.h) добавлен бит `LFJ8_H03_TIO9_ISOLATED` (`0x10`). `lfj8_h03_takeover_init` проверяет полную маску `0x1F` через существующий допуск. При отсутствии любой отметки объект остаётся без привязки, подготовка и выдача отклоняются. Новый бит устанавливает только владелец целевой конфигурации после подтверждения физической изоляции P97. Действующий `qualified` сохраняет ответственность за текущие разрешения. [Тест допуска](../../targets/lfj8/test_lfj8_h03_takeover.c)

## Проверки

- На ПК и M32R проверены прежняя маска `0x0F`, отсутствие каждого из пяти битов, посторонний бит и обычная подготовка/выдача с полной маской.
- Повторены 18 сценариев штатных выходов E/TIO9 и 59 сценариев мониторов и запрета. Пять проверок H03‑01 и оба профиля CAN‑05 из включённых порций снова прошли.
- На M32R прошли 22 группы штатных путей, восемь дополнительных групп и шесть групп размещённого кода. Компоновка `prefix-candidate` содержит 119 точек входа и 83 126 байт Flash. Запас основного окна составляет 596 байт, хвостовое окно заполнено. Результат компоновки `PASS_ADDRESS_MODEL_ONLY`.
- Размер секций `.text*` объекта `lfj8_h03_takeover.o` на M32R GCC 4.8.0 с `-Os` составил 1764 байта до и после изменения.
- На ПК прошёл 41 этап и 134 теста Python с проверенным S03. Первый прогон остановился из-за заполнения диска C:. Полный повтор выполнен с временными файлами и отчётами на D:. SHA-256 итогового `PC-CHECKS.json` — `9d3abc74bb642daf402d0416475fe253cadca4484e96734223637ab3a166b9ae`.

Изменение устанавливает условие допуска. Для передачи управления силовыми выходами остаются проверка физической изоляции P97, подтверждение снятия выходов на стенде и окончательная целевая привязка приложения. Для использования P97 как SLU потребуется отдельный проверенный силовой путь и отпускание по отказу. Новая физическая пара блоков в этой порции не испытывалась.
