# REL-01 — распознавание переименованных OFFLINE_ONLY

База проверки — `b2ca79d006426a9839d64e8553cd81bf71953fe9`.

Прежний `--firmware-pair` отклонял ELF и ярлык `OFFLINE_ONLY` в названии и записи сборки. Байтовая копия известного проверочного образа с обычным именем проходила после сверки с тем же SHA-256 в записи сборки.

В режиме пары упаковщик теперь сверяет SHA-256 также с архивными BIN, помеченными `OFFLINE_ONLY`, и проверочными `verification/**/manifest.json` с тем же статусом. Оба источника читаются из архива точного `source_commit`. При совпадении сборка ZIP останавливается. Обычный архив доказательств может включать такие образы. Проверки размера, ролей, статусов сборки, модели и стенда выполняются по прежнему контракту.

## Воспроизведение и проверки

- Три теста `tests/test_package_workset.py` прошли. До изменения два из них воспроизвели ошибку. Проверены архивный BIN, BIN, известный только по манифесту, сохранение доступа к обычному архиву и повторяемость синтетической пары при отсутствии совпадения.
- В отдельном временном каталоге сравнили прежний и новый упаковщики на исходном коммите и двух настоящих проверочных образах Bosch. Второй образ заново собрали обычным компактным профилем из закреплённых источников. В обоих прогонах прежний упаковщик принял проверочный файл под другим именем и с другим ярлыком. Новый упаковщик отказал до создания ZIP. В роли TCM был искусственный буфер правильного размера.
  - Архивный образ полей модели — `624d47d74bb19a6bdcf8aa662ec0b4e1361c51d635a9495765f36a6d7f0978f0`.
  - Обычный компактный профиль, присутствующий в проверочном манифесте — `bd0afefa40dfd1ea82e647ea5af7e64e2f652c27ccc5c3b91a986224fd77ec79`.
- `tools/verify_sources.py` подтвердил ТЗ, S01–S04 и точную основу `LFJ8-T-D.bin` H03. Исторические S05/S06 пропущены.
- Полный набор ПК с Zig 0.13.0 прошёл все 35 шагов, включая 74 теста unittest с закреплённым S03.

`project_status.py --check` прошёл на исходном коммите. На рабочей ветке новый снимок общего аудита требуется для упаковщика и его теста.

Проверка охватывает хеши, зафиксированные в исходном коммите. Сборки H03, проверки целевого арбитража и испытания оборудования не выполнялись. Выпуск пары BIN остаётся открытым.
