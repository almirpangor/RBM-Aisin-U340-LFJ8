# AUD-01. Проверка полноты архивной сверки E4M3

Ветка включает `main` `20bf48d15b27608a39876bc96aacae68c705863a` и предыдущую порцию `e340c619c4cd9677fbe56bde39535b888d8e9328`.

На предыдущей порции копия отчёта с удалёнными S02, сравнением E4M2 → E4M3 и группой копий E4M3 вернула `PASS_OFFLINE_ONLY` для семи файлов, двух сравнений и двух групп. Скрипт сверял перечисленные записи, но пропуск обязательной записи оставался незамеченным.

Перед чтением Git-объектов скрипт теперь проверяет наличие восьми архивных файлов, трёх исторических пар сравнения и полного состава трёх групп копий. Повтор группы, файла внутри группы или пары сравнения приводит к отказу. Порядок записей произволен. Дополнительные записи проходят ту же сверку байтов и смещений.

```powershell
python -B -m unittest discover -s tests -p test_e4m3_diff.py -v
python -B -m tools.check_e4m3_diff --r1 $r1 --r4 $r4
```

Прошли шесть целевых тестов. Контрольная копия с тремя пропусками отклонена. Полный архив R1/R4 повторно дал `PASS_OFFLINE_ONLY` для восьми файлов, трёх групп и всех 1057 диапазонов. `project_status.py --check` помечает скрипт и тест для включения в общий снимок аудита после приёмки. Выводы относятся к проверке архивных файлов на ПК.
