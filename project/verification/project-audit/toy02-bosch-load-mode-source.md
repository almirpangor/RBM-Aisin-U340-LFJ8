# TOY-02 — переключение источника нагрузки Bosch E4M3

База проекта `ae393e852fd8e110892c6725f219f3e43585d33c`. Аудит расширен на исходный участок `0x04A3B0–0x04A44F`. Участок побайтно совпал в закреплённых S04 E4M3 и REV8. Смещения указаны в адресах CPU ST10. [Проверка](../../targets/bosch/audit_toyota_load_producers.py) · [Предыдущая проверка потребителя](toy02-bosch-load-producers.md)

## Условия перехода

- В `0x04A3B0–0x04A411` снятие любого из `832A.0` и `832B.0` обнуляет счётчик `9224` и сбрасывает `832E.0`. При обоих единичных битах и счётчике меньше `9222` код увеличивает счётчик на один, сохраняя `832E.0`. Начиная с вызова, на входе которого `9224 ≥ 9222`, `832E.0` устанавливается при `T2.10 = 0` или `832F.1 = 1`. При `T2.10 = 1` и `832F.1 = 0` код сбрасывает `832E.0`.
- В `0x04A412–0x04A44F` `832E.0 = 1` сбрасывает `A88B.0` с приоритетом. При `832E.0 = 0` хотя бы один установленный бит `832C.0/832C.1` или снятый `832A.0` устанавливает `A88B.0`. В остальных случаях предыдущее значение сохраняется. Проверка включает оба исходных состояния `A88B.0` и `A88B.1`.
- Штатный потребитель переносит `A88B.0` в `PSW.6`. Инструкция `BMOVN` по `0x048886` инвертирует этот бит в `T2.5`. Закреплённый симулятор исполняет срезы до и после этой инструкции, а инверсия подаётся явно после сверки её байтов с руководством ST10. При `T2.5 = 0` результат опирается на `90E6`, при `T2.5 = 1` на `924E`. [STMicroelectronics, PM0036, стр. 69](https://www.st.com/resource/en/programming_manual/cd00147146-st10-family-programming-manual-stmicroelectronics.pdf#page=69)

## Проверки

- В C167 прошли 64 комбинации входов и предыдущих состояний. Девять вызовов с сохранением памяти проверили накопление, проверку на входе следующего вызова после достижения порога, приоритет `832F.1`, восстановление и сброс счётчика по каждому из двух входов. Порог `9222 = 2` выбран для проверки.
- В отдельной последовательности установки, удержания, сброса, удержания и восстановления потребитель выдал `F8D6 = 1500, 1500, 2500, 2500, 1500` при неизменных подставленных `90E6 = 1000`, `924E = 2000` и `9156 = 500`. Повторены десять сверок окон S04/REV8 и прежние тесты вычисления `F8D6`, `F8CF` и `9680`.
- Повторены `audit_bosch_signal_transport.py` и `audit_toyota_load_inputs.py`. Оба дали `SOURCE_AUDIT_OFFLINE_ONLY`. `audit_toyota_load_traces.py` вновь показал ноль парных переходных отсчётов для Bosch и S01.

