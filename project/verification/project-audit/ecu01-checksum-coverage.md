# ECU-01 — полнота таблицы контрольных сумм E4M3

База проекта `4fd3f71ed547520d5c489f29f0b29e6e1d6b0659`. Источники проверки — R4 `dc6b4f08a24e648d3d0dab986c1765abb6fd294a` и S04 `e25a1c97492ae556b1a52043e6ae85b88d2da86c03a78ef01dc2151c8a0a4a2a`. Для модели ST10 использован `tools/c167_subset.py` из R3 `7585de6945b4b6b3ef381c6062070a5f417cf588`.

## Регрессия

В проверочном прогоне обёртка `diag.checks` возвращала исходный список для S04, а после выбора источника скорости `CALIBRATION=0x20` исключала первую запись с неверной суммой (`0xA7830`). Старый сборщик вернул образ с 50 записями в манифесте. Повторная проверка полной таблицей показала неверную сумму для `0xA7830`. С новым кодом тот же прогон завершился ошибкой до выдачи образа.

Сборщик проверяет набор из 48 записей в `[0xA7800, 0xA7B00)` с шагом 16 и трёх записей по `0xA83CC`, `0xA83DC` и `0xA83EC` на каждом проходе пересчёта и при итоговой проверке. В unit-тестах полный список с обратным порядком принят, пустой и неполный списки, дубль и постороннее смещение отклонены.

## Повторённые проверки

- Сборка всех четырёх профилей — только скорость, RPM/ОЖ, поля модели и обычный режим — с абсолютными и компактными ветвлениями. Во всех восьми вариантах BIN совпали побайтно, а манифесты — по всем полям. Каждый манифест содержит 51 запись.
- Команды BOSCH из карточки ECU-01 прошли. Обычный компактный профиль дал прежний SHA-256 `bd0afefa40dfd1ea82e647ea5af7e64e2f652c27ccc5c3b91a986224fd77ec79` для 851 968 байт.
- Модель ST10 вернула `PASS_OFFLINE_ONLY`. Проверены 56 сценариев допуска режима, 65 536 случаев кодирования, 64 сценария квалификации кадра, 6 случаев изменения входов и 3 случая задержки IF1.
- `python -B -m unittest discover -s tests -v` прошёл. Всего 68 тестов.

`project_status.py --check` прошёл на исходном коммите. На рабочей ветке общий снимок помечает `targets/bosch/build.py` и `tests/test_bosch_build_integrity.py` до обновления интегратором.

Оборудование не проверялось. Окончательный профиль CAN, калибровка момента и приёмка пары TCM/ECU остаются открытыми.
