# DTC-03 — штатный монитор цепи ATF H03

Основа — `b2ca79d006426a9839d64e8553cd81bf71953fe9`. Проверен `LFJ8-T-D.bin` (H03, 524 288 байт, SHA-256 `844a11b809cda1f2ccaf90cb6a75666009487ccedd2e8190b7eb46137b855544`).

Штатный вызов `0x0725B0 → 0x0753A4` контролирует напряжение AN1 из `0x804F04`. Границы строгие: больше `0x0165DC` (0,058594 В) и меньше `0x0165D8` (4,667969 В). При штатном пересчёте `raw × 5/1024` допустимы отсчёты 13–956 включительно. На самих границах запускается соответствующая ветвь отказа. [Тракт AN1](../../docs/lfj8-h03-input-paths.md)

| Признак | Остаток счётчика | RAM |
| --- | --- | --- |
| Высокий сигнал | `0x805EE4` | `0x8065EB` |
| Низкий сигнал | `0x805EE8` | `0x8065EC` |
| Отказ цепи, общий | — | `0x8063E7` |
| Выдержка восстановления пройдена | `0x805EFC` | `0x8065F0` |

Два направленных счётчика загружаются штатным значением 150 000 из `0x01672C`. При срабатывании ветви `0x8062DA/0x8062DC` они могут загружаться значением 1 000. Код также учитывает разрешающие признаки `0x8065F3/0x8065B6/0x8065B7`. Счётчик восстановления загружается значением 2 000 из `0x016730`. Код отнимает накопленный шаг из `0x805F10` и ограничивает остаток нулём. Это числа из ROM H03. Перевод в измеренное время на блоке требует подтверждения шага и расписания.

При смене направления без завершённого восстановления штатный монитор сохраняет первую защёлку, и могут оказаться активны обе. Сервисный путь `0x072390` при установленном `0x80637C` обнуляет общий флаг и признак восстановления, но сохраняет направленную защёлку. В модели она снова видна, если до восстановления подтвердился противоположный отказ. Только выдержка исправного напряжения очищает обе причины в проверенном пути монитора.

## Программный результат

`lfj8_h03_atf_circuit_after_monitor` читает четыре признака H03 в одной критической секции. После подтверждённого вызова монитор может сообщить низкий сигнал, высокий, обе защёлки либо пройденное восстановление. При старте, после сервисного сброса или при противоречивом снимке функция возвращает `UNKNOWN`, и потребитель сохраняет прежний диагностический статус до достоверного события. Вызов и контроль давности принадлежат владельцу расписания. [Реализация](../../targets/lfj8/lfj8_h03_atf_fault.c) · [Контракт](../../targets/lfj8/lfj8_h03_atf_fault.h)

Слова P0712 и P0713 подтверждены в таблице H03 по `0x031510` и `0x031524`. Проверка исполняет монитор и читает его защёлки. Путь публикации этих записей в штатном сеансе Mazda остаётся открытым. Для Chery S03 подтверждён общий P0710 с индексом `0x04`. Автоматическое соответствие каждой направленной защёлки этому индексу требует правила активации, хранения и очистки. В этой порции используется отдельный статус цепи ATF. [Матрица Toyota/Chery](../../docs/diagnostics-integration.md)

## Проверки

- **Отдельная сборка и модель M32R.** GCC 4.8.0 собрал тестовый ELF. Симулятор исполнил штатный монитор и сервисную ветвь из неизменённого ROM с управляемыми входами. Проверены 20 сценариев, включая обе точные границы, срабатывание на 30-м вызове при тестовом шаге 5 000, прерывание выдержки, альтернативные разрешения, сокращённый счётчик, восстановление на четвёртом вызове при шаге 500, повторную фиксацию после сервисного сброса и отклонение противоречивых снимков. [Воспроизводимая проверка](../../targets/lfj8/check_h03_atf_fault.py)
- **Отрицательные сценарии.** Во временных копиях адаптера проверка обнаружила перестановку адресов низкого и высокого сигналов и ошибочное подтверждение восстановления после сервисного сброса.
- **ПК.** Основной набор прошёл 35 шагов и 71 тест Python, включая проверку закреплённого S03 по `RBM_S03`. Новый адаптер собран отдельно с Zig 0.13.0 и строгими предупреждениями.
- **Сборка моста.** Стандартный `--base-9e1c` включает адаптер в перемещаемый объект H03 и отмечает исходник в манифесте. `nm` подтверждает экспорт функции. `check_h03_link.py` прошёл сквозную модель и 17 компонентных прогонов. Проверены также три прогона штатной сборки моста для ПК. [Сборка](../../targets/lfj8/build.py)

```powershell
python -B targets/lfj8/check_h03_atf_fault.py --base $h03 --gcc $m32rGcc --out local/audit/h03-atf-fault.json
python -B tools/build_pc_checks.py --cc $zig --out local/pc-checks
python -B targets/lfj8/build.py --output local/audit/bridge-host --zig $zig
python -B controller/build_target.py m32r --cc $m32rGcc --out local/audit/controller
python -B targets/lfj8/build.py --output local/audit/bridge --m32r-cc $m32rGcc --base-9e1c $h03
python -B targets/lfj8/check_h03_link.py --base $h03 --gcc $m32rGcc --bridge local/audit/bridge/lfj8_9e1c_m32r.o --controller local/audit/controller/rbm_u340e_m32r_be.o --out local/audit/h03-link.json --bosch-trace verification/e4m3-can-9e1c/ordinary-model/round-trip.json
```
