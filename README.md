# Блок управления АКПП Aisin U340E

Проект RB Motors для Aisin U340E, отдельного Mazda TCM `LFJ8-18-9E1C` и двигателя GW4G15 с Bosch ME7.9.71 E4M3. Владелец подтвердил выбор TCM и штатные цепи его подключения. Переключения моделируются по Toyota U340E, обмен между блоками восстанавливается по Chery Tiggo T11 и Continental TA2005.

**Статус выпуска.** Комплект программной проверки содержит исходники, объекты для компоновки, ELF для симулятора M32R и отчёты. Целевые BIN по ТЗ ещё не выпущены. Стендовая приёмка ожидает завершения целевой интеграции. [Состояние по требованиям ТЗ](docs/working-set.md)

Для воспроизведения проверки CAN сохранён экспериментальный BIN **двигателя Bosch E4M3** для симулятора ST10. В сквозном тесте приёмник LFJ8 обработал два поля двигателя в `0x0FA`. Потеря и восстановление каждого поля проверены по штатным инструкциям TA2005 и по ответам диагностического сеанса на M32R. [Образ Bosch и результаты проверок](verification/e4m3-can-9e1c) · [Обработка U1120 и U112B](docs/diagnostics-integration.md#потеря-двух-полей-двигателя-в-кадре-0x0fa)

В программных прогонах 9E1C пройдены переход P/N→D на месте, выход на первую и переключение 1→2. Для модельного переключения 2→3 отдельно проверен диалог снижения момента Toyota ↔ Bosch. Диагностический адаптер подтверждает передачу `0x722` по окончанию отправки в модели CAN0. [Включение D](controller/tests/test_runtime.c) · [Диалог момента](docs/lfj8-h03-torque.md) · [Диагностика CAN0](docs/diagnostics-integration.md#привязка-диагностического-сеанса-к-can0-h03)

В отдельном прогоне исходные фазы H03 приняли рассчитанную Toyota команду включения D. Квалификация оборотов и ОЖ проверена по машинным инструкциям TA2005. Второй офлайн-профиль Bosch передаёт три поля модели в обычном режиме и проходит сквозной прогон M32R. [Связка цикла и выходов](docs/lfj8-h03-control-cycle.md) · [Результаты режима без круиза](verification/e4m3-can-9e1c/ordinary-model)

Для разработки владелец выбрал `LFJ8-T-D.bin` с внутренним номером `9E1C`. Компоненты привязываются к адресам этого образа и собираются под M32R. Владелец подтвердил, что будет использовать блок под `9E1C`. Образ `9E1B` используется для сравнения, а `RB-J-P01.bin` хранится как проверенный исходник моторного PCM `881F`. [Сверка образов Mazda](docs/lfj8-target-identity.md)

## Проверка исходных файлов

Для воспроизведения проверки нужны Git, Python 3.10 или новее, доступ на чтение к R1 и предоставленный владельцем `RB-J-P01.bin`. Подставьте локальные пути к PCM S05 и донору TCM S06.

```powershell
git clone --no-checkout https://github.com/almirpangor/CM-AVEO-TCM-AKP-U340.git .sources/R1
python tools/verify_sources.py --donor-repo .sources/R1 --pcm-image 'C:/path/to/RB-J-P01.bin' --tcm-donor 'C:/path/to/LFJ8TB000LFXA0A0-20260806-160523(TCM-adapt).bin'
```

Проверка сравнивает фактические размеры и SHA-256 с реестром. Для S01–S04 она также сверяет идентификаторы Git blob в зафиксированном коммите. Проверки внутренней целостности Mazda и Bosch описаны в отчётах соответствующих сборок.

Для первичной сверки архивного или считанного образа TCM по встроенным метаданным:

```powershell
python -B tools/inspect_lfj8_tcm.py 'C:/path/to/TCM.bin'
```
