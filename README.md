# Блок управления АКПП Aisin U340E

Проект RB Motors для отдельного Mazda TCM **LFJ8-18-9E1C**, коробки **Aisin U340E** и двигателя **GW4G15 с Bosch ME7.9.71 E4M3**. Алгоритмы восстанавливаются из Toyota S01, обмен исследуется по Chery Tiggo T11 и Continental TA2005.

Действуют последние решения владельца. Публикация проекта в GitHub возобновлена по указанию от 20.11.2026. Запись в блок выполняет владелец. Два дополнительных реле и импульсный выход панели отложены; скорость по CAN остаётся в первом файле.

## Состояние проекта

### Куда идти дальше

1. [DTC-02: Штатный приём BasicCAN для диагностического сеанса](docs/project-map.md#dtc-02). Исследовать и реализовать когерентный захват статуса/DLC/данных до очистки TRFIN, передачу очереди и фильтр поколения. Сохранить штатную диагностику.
2. [CAN-03: Штатный запуск, IRQ и восстановление CAN0](docs/project-map.md#can-03). Подключить арбитраж ко всем вызовам OEM 0x00C34C, запуску/сбросу CAN и RAM владельца. Измерить окна TX→RX и период опроса.
3. [H03-03: Единое расписание и запуск приложения H03](docs/project-map.md#h03-03). Подключить foreground-потребителя, начальную инициализацию, владельцев снимков и callback. Раздельно установить ритмы H03 и Toyota, измерить выполнение и IRQ.
4. [TOY-02: Подтверждённая нагрузка двигателя для Toyota](docs/project-map.md#toy-02). Определить источник и шкалы GP−9046/−8288/−8330 и флаги режимов либо полные результаты арбитража. Подключить квалификацию и отказы.
5. [TOY-03: Независимые разрешающие сигналы диапазона](docs/project-map.md#toy-03). Установить соответствующие входы H03, условия обновления и недостоверности.

Этот порядок относится к доступной программной работе. Незакрытая зависимость ограничивает интеграцию, но не мешает отдельно исследовать модуль. Физические ограничения перечислены в карточках и в [протоколе приёмки](docs/lfj8-9e1c-minimum-bench.md).

### Быстрое продолжение

```powershell
python -B tools/project_status.py --check
python -B tools/project_status.py --task DTC-02
```

Первая команда проверяет ссылки, зависимости, актуальность карты и контрольные суммы проверенного кода/отчётов. Она не повторяет симуляции. Вторая показывает точные файлы, настройки, ограничения и команды выбранной подзадачи. При изменении кода повторяются затронутые проверки.

Статусы редактируются в [едином реестре](data/project-tasks.json), затем страницы обновляются командой `python -B tools/project_status.py --write`. Сам отчёт проверки этой командой не обновляется.
