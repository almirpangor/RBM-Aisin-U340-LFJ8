# Блок управления АКПП Aisin U340E

Проект RB Motors для Aisin U340E, отдельного Mazda TCM `LFJ8-18-9E1D` и двигателя GW4G15 с Bosch ME7.9.71 E4M3. Владелец подтвердил выбор TCM и штатные цепи его подключения. Переключения моделируются по Toyota U340E, обмен между блоками восстанавливается по Chery Tiggo T11 и Continental TA2005.

**Статус выпуска.** Комплект программной проверки содержит исходники, объекты для компоновки, ELF для симулятора M32R и отчёты. Целевые BIN по ТЗ ещё не выпущены. Стендовая приёмка ожидает завершения целевой интеграции. [Состояние по требованиям ТЗ](docs/working-set.md)

Для разработки владелец выбрал `LFJ8-T-D.bin` с внутренним номером `9E1C`. Компоненты привязываются к адресам этого образа и собираются под M32R. Возможность записи в физический `9E1D` проверяется отдельно. Образ `9E1B` используется для сравнения, а `RB-J-P01.bin` хранится как проверенный исходник моторного PCM `881F`. [Сверка образов Mazda](docs/lfj8-target-identity.md)

## Проверка исходных файлов

Для воспроизведения проверки нужны Git, Python 3.10 или новее, доступ на чтение к R1 и предоставленный владельцем `RB-J-P01.bin`. Подставьте локальные пути к PCM S05 и донору TCM S06.

```powershell
git clone --no-checkout https://github.com/almirpangor/CM-AVEO-TCM-AKP-U340.git .sources/R1
python tools/verify_sources.py --donor-repo .sources/R1 --pcm-image 'C:/path/to/RB-J-P01.bin' --tcm-donor 'C:/path/to/LFJ8TB000LFXA0A0-20260806-160523(TCM-adapt).bin'
```

Проверка сравнивает фактические размеры и SHA-256 с реестром. Для S01–S04 она также сверяет идентификаторы Git blob в зафиксированном коммите. Проверки внутренней целостности Mazda и Bosch описаны в отчётах соответствующих сборок.

Для первичной сверки архивного или считанного образа TCM по встроенным метаданным:

```powershell
python -B tools/inspect_lfj8_tcm.py 'C:/path/to/TCM.bin'
```
