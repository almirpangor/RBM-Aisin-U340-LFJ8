RB Motors • Aisin U340E • H03 и Bosch E4M3
26 ноября 2026 года

Текущий статус — OFFLINE_ONLY. В каталоге offline/ лежат два проверочных BIN. Запись в автомобиль или на стенд для этой версии не предусмотрена. Оба файла можно заново собрать из приложенных исходников и донорских образов.

Что открыть
• СВЕРКА_ТЗ.txt — требования по каждому из 11 разделов и фактические результаты.
• project/docs/RBM_TZ_Aisin_U340_LFJ8_Codex_v1_0.pdf — исходное ТЗ, 13 листов.
• project/docs/decisions.md — переход на 9E1C и уточнения владельца.
• project/docs/lfj8-wiring-sources.md, project/docs/verification.md и project/docs/lfj8-9e1c-minimum-bench.md — подтверждённые соединения, порядок проверки и план восстановления/приёмки.
• project/ — исходники основной разработки, модель, проверки и документация. Отдельные документы содержат датированные результаты прежних сборок.
• components/ — проверенные отдельно изменения запуска и профиля H03.
• sources/bosch-passive/ и sources/R4/ — код именно переданного варианта Bosch и нужные компоненты двигателя из зафиксированного R4.
• inputs/ — неизменённый оригинал H03 и четыре согласованных донора. Только файлы из offline/ — результаты данной выдачи.
• checks/ — фактические отчёты. release.json и SHA256SUMS.txt связывают выдачу с проверенными бинарниками и содержимым архива.

Повторить сборку
Распакуйте архив. Из его корневой папки в Windows с Python 3.13 выполните команду ниже. Она создаст новый каталог с двумя BIN, пересчитает SHA-256, сравнит их с проверенными файлами и повторит моделирование приёмника Bosch. Включён Windows-компилятор M32R GCC 4.8.0. Внешние Python-пакеты для этой команды не требуются.

python -X utf8 -B rebuild.py --out rebuilt --verify

Параметр --out задаёт новый каталог. Готовые файлы находятся также в offline/. В исходном H03 при сборке заменяются только проверенные участки из checks/image/H03-M32R.json. Собираемый код охватывает ранний запуск и защиту сервисных операций. Для Bosch создаётся полный образ E4M3 со штатным пассивным приёмом d1/d4 в 0x1AE. Эта версия ещё не управляет моментом GW4G15 по этим двум байтам.
